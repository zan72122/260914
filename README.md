# パカッ！とろとろオムライス

iPhone / iPad の Safari で遊ぶ、**一本指・文字なし**のブラウザゲームです。
白いご飯にケチャップをかけて混ぜ、卵を焼いてオムライスにのせ、切って「パカッ！」と開き、
とろとろの卵の上に好きな絵を描く——その一周だけを、できるだけ気持ちよく作ってあります。

- 対象: **4歳くらいの子ども**（読み書き不要）
- 操作: **指1本だけ**。タップ・長押し・なぞる、の3つしか使いません
- 画面: iPhone / iPad の **縦・横どちらでも**。途中で回しても遊んでいる途中の状態は消えません
- 文字・点数・時間制限・失敗はありません。×印も出ません
- ビルド不要。`index.html` + ES modules + Canvas 2D だけ。外部ライブラリはゼロ

---

## 遊び方（一周）

工程は9つ。どれも「次に触るもの」だけが光ったり揺れたりして誘うので、説明は要りません。

| # | 状態 | 画面 | 指の動き |
|---|---|---|---|
| 1 | `RICE_KETCHUP` | 白いご飯の皿とケチャップのボトル | ボトルを**つかんでご飯の上をなぞる**。赤い線が出る。皿に近づくとボトルが自分で傾く。十分かかると次へ |
| 2 | `RICE_MIX` | ヘラが皿の縁でぴょこぴょこ誘う | ご飯の山の上を**ぐるぐるなぞる**。なぞったところが白→赤に変わり、8割で一気に混ざってチキンライスにまとまる |
| 3 | `EGG_POUR` | 卵のボウルが揺れて誘う | ボウルを**フライパンの上へドラッグ**（フライパンをタップでも注げる）。黄色い卵液がジュワッと広がる |
| 4 | `EGG_GATHER` | フライパンいっぱいの卵 | フライパンの上で**真ん中に向かって何度かスワイプ**。黄色が中央へ寄って、ぷるぷるの半熟オムレツになる |
| 5 | `EGG_SLIDE` | 皿のライスとフライパンのオムレツ | **フライパンを皿のほうへドラッグ**。フライパンが傾いて皿の縁まで寄り、オムレツがスルッと滑ってライスに乗る |
| 6 | `CUT` | オムレツの真ん中に光る稜線 | 稜線に沿って**一筋なぞる**（縦でも横でもよい／吸着するので雑でよい）。つまずいたときは**3回タップ**でも切れる |
| 7 | `OPEN` | — | 見せ場。切れ目からパカッと両側が倒れ、とろとろの卵が流れ出す（約1秒、操作なし） |
| 8 | `DRAW` | 開いた黄色い面がキャンバス | **指でなぞる**と艶のあるケチャップの線が描ける。ボトルは皿の横で待っている |
| 9 | `DONE_MENU` | 絵だけの3つのボタン | 🔁 もう一回 ／ ✨ 別バージョン（皿・ケチャップ・卵の色が変わる）／ 🖌 描き直し |

うまくいかないときは、**押し間違えが続くほど「触るべきもの」の光が強くなります**。
また EGG_GATHER などには保険のタイマーが入っていて、雑に触り続けるだけでも必ず先へ進みます。

## 起動方法

```bash
npm run serve          # python3 -m http.server 8080
```

ブラウザで <http://localhost:8080> を開きます（ビルドもインストールも不要）。

### iPhone / iPad の実機で遊ぶ

1. PC と iPhone を**同じ Wi-Fi** につなぐ
2. PC の IP アドレスを調べる（`ipconfig getifaddr en0` / `hostname -I` など）
3. iPhone の Safari で `http://<PCのIP>:8080` を開く（例: `http://192.168.1.23:8080`）
4. 「ホーム画面に追加」すると、アドレスバーのないフルスクリーンで遊べます

音は iOS の制限で**最初のタップのときに鳴りはじめます**（それまで無音なのは仕様）。

## テスト

Playwright（Chromium）で、一本指の操作だけを使って一周を自動プレイします。

```bash
PLAYWRIGHT_BROWSERS_PATH=/opt/pw-browsers npm test      # 全部（一周 × 4画面 ＋ UX 監査 ＋ 演出フレーム）
PLAYWRIGHT_BROWSERS_PATH=/opt/pw-browsers npm run frames # 演出のコマ送りだけ書き出す
PLAYWRIGHT_BROWSERS_PATH=/opt/pw-browsers npm run sheet  # 書き出したコマを1枚のシートに並べる
```

| スクリプト | 中身 |
|---|---|
| `npm test` | `tests/play.spec.js`（iPhone/iPad の縦横4通りの一周・回転保持・別バージョン・道具が画面から切れないこと）、`tests/audit.spec.js`（4歳児の雑な操作でも詰まらないことの実測）、`tests/frames.spec.js` |
| `npm run frames` | `screenshots/frames/` に「滑って乗る」「パカッ→トロッ」を 60ms 刻みで書き出す |
| `npm run sheet` | `tests/sheet.js` でコマを連結したレビュー用シートを作る（画像合成に Chromium を使うので同じ環境変数が要る） |

**`PLAYWRIGHT_BROWSERS_PATH` に注意**: この環境のブラウザは既定の `~/.cache/ms-playwright` ではなく
`/opt/pw-browsers` にあります。付けずに実行すると「Executable doesn't exist」で落ちるので、
`PLAYWRIGHT_BROWSERS_PATH=/opt/pw-browsers` を必ず前に付けてください。

**@playwright/test を 1.56.0 に固定している理由**: `/opt/pw-browsers` に置かれているブラウザ
（`chromium-1194`）は 1.56.0 が要求するビルドです。バージョンを上げると別のビルド番号を探しに行き、
オフラインではダウンロードできずテストが動かなくなります。ブラウザを入れ替えられない限り上げないでください。

`webServer` は `playwright.config.js` が `python3 -m http.server 8080` を自動で起動します
（`reuseExistingServer: true` なので、先に `npm run serve` を動かしてあればそれを使います）。
うまく立ち上がらないときは `python3 -m http.server 8080` を別ターミナルで常駐させてから実行してください。

スクリーンショットは `screenshots/`（git 管理外）に出ます。

## 設計原則

**1. Wordless Interaction（文字で説明しない）**
次の操作は、文章ではなく世界が誘います。触るべきものだけが呼吸するように光り、揺れ、
艶が走ります。切る場所には端から端へ光が走り、寄せる場所には光のさざ波が立ちます。
×印や「もう一度」のような否定は出さず、吸着・補正・やわらかい戻りで成功に導きます。

**2. 状態はレイアウトに依存しない**
`src/state.js` は画面サイズを一切持ちません。皿の上のものは**皿ローカルの正規化座標 (u, v)**
（皿の半径を 1 とする座標）で保持し、描くときだけ `toScreen()` で画面座標に変換します。
だから画面を回しても、`computeLayout()` で座標系を作り直すだけで、
かけたケチャップも混ざり具合も描いた絵もそのまま残ります。

**3. 道具の絵は必ず画面の中に入れる**
道具（ボトル・ヘラ・ボウル）は、**描画したピクセルから実測した外接箱**（`TOOL_BOX`）を持ち、
回転を考慮した外接矩形ごと、セーフエリアの内側に **8px 以上の余白**を残す位置へクランプされます
（`layout.js` の `clampTool()`。定位置・誘いの位置・指への追従・毎フレームの最後、すべてに掛かる）。
皿の縁で誘うヘラは、上端に近くて柄の先が窮屈になる画面（iPad 縦など）では、
誘う向きを皿の右 → 右下 → 下 … と自動で回します。

**4. 指で隠れないように**
つまむ位置は指より少し上、ケチャップのノズルは指の少し先。変化は指の外側で見えるようにします。
当たり判定はすべて「ざっくり」で、44pt よりかなり大きく取ってあります。

## 既知の課題

- **実機 Safari では未検証**。自動テストは Chromium（Playwright）だけです。iOS Safari 特有の
  `100dvh` の伸縮、ホームバーのセーフエリア、AudioContext の解錠タイミング、
  低電力モードでのフレーム落ちは、実機で確かめる必要があります。
- セーフエリアは `env(safe-area-inset-*)` を CSS 変数経由で読んでレイアウトに渡していますが、
  実機のノッチ／ホームバーでの見え方は未確認です（テストでは常に 0）。
- 音は短い合成音のみ。iOS のサイレントスイッチが入っていると鳴りません。
- 2本指で同時に触ったときは最初の指だけを見ます（意図通りですが、兄弟で同時に触ると片方が無反応に見えます）。
- 描いた絵の保存・共有はできません（「もう一回」で消えます）。
