# Tower Cake — 超高層ウェディングケーキ建設ゲーム

4歳児が iPhone / iPad の縦画面・横画面で **一本指だけ** で遊べる、文字・矢印・説明なし(Wordless Interaction)の Web ゲームです。
下段から巨大なウェディングケーキを積み上げ、最後にトッパーを置いた瞬間だけカメラが大きく引いて全高が初めて見えます。

## 遊び方(言葉は要りません)

世界の中で「未完成なもの」「揺れているもの」「光っているもの」が次に触る場所です。
3秒ほど触らないと、半透明の指が操作をなぞって見せます。

## 動かし方

依存ライブラリ・ビルドはありません。`index.html` を開くだけで動きます。

```
python3 -m http.server 8000   # → http://localhost:8000/
```

GitHub Pages などの静的ホスティングにそのまま置けます。

## 構成

| ファイル | 役割 |
| --- | --- |
| `index.html` | 全画面キャンバス、viewport 設定 |
| `js/util.js` | 数学ユーティリティ、円筒側面の被覆グリッド、パーティクル |
| `js/audio.js` | WebAudio による効果音合成(素材ファイルなし) |
| `js/render.js` | カメラ、高度で変わる背景、リフト作業台、パティシエ、各段の材質描画 |
| `js/steps.js` | 各工程(Step)の入力・物理・描画・ヒント |
| `js/game.js` | 段の定義と工程の並び、入力、カメラ追従、メインループ |
| `test/autoplay.js` | Playwright で「ヒントのジェスチャーだけ」で全工程を一本指自動試遊し、工程ごとにスクリーンショットを保存 |

## 段ごとの固有動作

| 段 | 構造 | 表面 | 装飾 |
| --- | --- | --- | --- |
| 1 土台 | ホイストから巨大スポンジを吊り下ろす | クリーム塗り → ターンテーブル回転+固定スクレーパー → 巨大フォンダンを「ファサッ」→ 撫でてシワ抜き → 裾を一周切る | 縁にパール(速さで間隔が変わる) |
| 2 ダブルバレル | ボードで位置跡 → ダボ差し → 一気に水平カット → 1段目 → ジャム塗り → 2段目 → 中央支柱を長押しで打ち込む(内部が X 線表示) | ガナッシュを縁から注いで垂らす → スクレーパー → 巨大フォンダン | リボンを巻いて(ケーキが回る)端をタップで蝶結び |
| 3 浮遊段 | 透明柱をタップで立てる → 透明プレートごと吊り下ろす | クリーム → スクレーパー | 波線を引くとフリル(揺れ幅・折り数が線に残る) |
| 4 レース段 | ボード → ダボ → 水平カット → 吊り下ろし | クリーム → フォンダン → シワ抜き → 裾切り | レースマットを貼ってこすり、剥がすと模様が転写 → 長押しで大輪の花が咲く |
| 5 ゴールド段 | ボード → ダボ → 水平カット → 吊り下ろし | クリーム → スクレーパー | こすって金箔(速いと剥片状) → 3 段をまたぐ花のカスケード |
| 6 スワッグ段 | ボード → ダボ → 水平カット → 吊り下ろし | クリーム → フォンダン → シワ抜き → 裾切り | 点から点へ引くと垂れ下がるスワッグ |
| 7 最上段 | 吊り下ろし | クリーム → スクレーパー | 篩をタップで粉糖の雪 → トッパーを置く → **Reveal** |

## 検証

```
NODE_PATH=$(npm root -g) node test/autoplay.js 390 844 out/portrait    # iPhone 縦
NODE_PATH=$(npm root -g) node test/autoplay.js 844 390 out/landscape   # iPhone 横
NODE_PATH=$(npm root -g) node test/autoplay.js 820 1180 out/ipad       # iPad 縦
```

自動プレイは各工程の `hint()`(ゴーストの指が示すジェスチャー)だけを入力にするため、
「見れば分かる誘導だけでクリアできるか」の確認にもなります。
