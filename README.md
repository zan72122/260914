# ふるふる すなもようラボ

4歳児向けの、文字のない（wordless）クラドニ図形（Chladni plate）砂遊びブラウザゲーム。
スコア・勝敗・制限時間・クリアはありません。ぜんぶ一本指でさわって遊びます。

金属の板に砂をふりかけ、周波数ノブを回すと板がふるえて砂がひとりでに模様をつくります。

## 起動方法

依存ライブラリなし・ビルド不要です。ES modules を使うので `file://` ではなく HTTP で開いてください。

```sh
cd <このフォルダ>
npx http-server -p 8080
# → http://localhost:8080/ をブラウザで開く
```

`python3 -m http.server 8080` など他の静的サーバーでも動きます。
iPhone / iPad で試すときは、同じ Wi-Fi 上の PC で上記を起動し、
`http://<PCのIPアドレス>:8080/` を Safari で開いてください。

## 操作一覧（すべて一本指・文字表示なし）

| 器具 | 操作 | 起きること |
| --- | --- | --- |
| 砂入れ（ボウル） | タップ | ボウルから板へ砂が弧を描いて飛び、板の上に約60粒（＋押している間の分）が散らばる。器が傾く |
| 砂入れ | 押しっぱなし | 毎秒およそ150粒が板へ降り続ける（指がボウルの上＝板の外でも、砂はちゃんと板に届く） |
| 砂入れ | 板の上までドラッグ | 指の位置が優先され、指のところから直接砂が降る。板の外側へ出すとこぼれて消える |
| 周波数ノブ | ノブ中心まわりに円弧ドラッグ | 角度に追従して回る。指が中心から離れていてもOK |
| 周波数ノブ | タップ | 1段階進む。いちばん端まで行くと停止（0）に戻る |
| 板ラック（上／左の3枚） | タップ | 正方形・円形・三角形の板が中央にスライドして装着。砂は大半がこぼれる |
| 振動位置ソケット（3つの穴） | 空いた穴をタップ | 黄色いプラグが移動し、ドライバ位置が変わって模様が変わる |
| 板の上 | ドラッグ（こする） | 指のまわりの砂が散る |
| 板の上 | タップ | 小さく散る |
| 板の上 | 強くこすり続ける | 板全体の砂が吹き飛ぶ |
| 台の空きスペース | タップ | 何も起きない（誤操作で壊れない） |

ノブが 0 のときは停止（砂は静止）。少しでも回すと音と板の振動と砂の跳ねが同時に始まります。

### 最初の一手の誘導（wordless）

文字は一切出しません。次に触ってほしい器具が光の輪でやわらかく強調され、
10秒さわらないでいると、その器具が軽く揺れます。
順番は 砂入れ → ノブ → 板ラック → ソケット。

## 科学モデル（実装の要約）

粒子は板ローカル座標 (u,v) ∈ [-1,1]² で持ち、節線関数 f(u,v) の `|f|` が小さい場所（節線）へ
勾配降下で集まります。あわせて振幅 `|f|` に比例したランダムな跳ね（ジッター）が入るため、
腹の部分では跳ね回り、節線の上だけに残ります。板の形のマスクから出た粒は縁からこぼれて消えます。

- **正方形**: `f = cos(nπx)cos(mπy) − cos(mπx)cos(nπy)`（自由板の古典近似）と、
  その対称版 `cos(nπx)cos(mπy) + cos(mπx)cos(nπy)` の2基底の重ね合わせ。
- **円形**: 極座標で `cos(kπr)·cos(nθ)`（角方向モード）と `cos(k'πr)`（同心円モード）の2基底。
  中心では角方向モードが立たないようテーパーを掛けてあるので、中央ドライバでは同心円になります。
- **三角形**: 正三角形の3辺の法線方向 d_i について `Σcos(k·d_i)/3` と `Σcos(2k·d_i)/3` の2基底。
  かならず3回対称の幾何学模様になります。

**周波数ノブ**は連続に回せますが、12段階の離散モードに量子化して割り当てています。
段の終わり28%でつぎのモードへブレンドするので、切り替わる瞬間に模様が崩れて再構成される様子が見えます。

**振動位置（ソケット）**は、そのドライバ位置での2基底の値を混合係数に使います
（= その点が腹になるモードが選ばれる）。さらにソケットごとの性格づけ（中央＝反対称／角＝対称／縁＝その差）を
バイアスとして加えているので、ドライバ位置がたまたま節に来ても3つのソケットは必ず違う模様になります。

節線をくっきり出すため、グリッドに焼く値は `|f|/max` そのままではなく `pow(|f|/max, 0.6)` に圧縮しています
（節線付近の勾配が強くなる）。あわせてジッターを振幅の**2乗**に比例させているため、
節線に乗った砂はほとんど跳ねず、線が細く締まります。

**収束判定**は粒子の平均振幅が閾値（0.15、圧縮後の値。生の `|f|/max` では約0.045）を下回ったとき。板がふわっと光り、砂粒がきらめき、
短い和音が鳴ります。完成後も振動は続き、ノブ・板・ソケットを変えるとまた崩れます。

## パフォーマンス

- Canvas 2D のみ（WebGL不使用）。devicePixelRatio は最大2に制限。
- 粒子数は画面の短辺から 1500〜3500 に自動決定（iPhone 390pt 幅で約1900）。
- 砂粒は `fillRect` 1回で描く正方形。1辺は DPR を考慮して 2.2〜3.6 物理px（DPR2 の iPhone でおよそ 3物理px）。
- 節線場は 113×113 のグリッドに一度だけ焼き、毎フレームはバイリニア補間で読むだけ。
  グリッドの再計算はモード／板／ソケットが変わったときのみ。
- 実験台の木目と金属板はオフスクリーンキャンバスにキャッシュして毎フレームの再描画を避けています。
- ヘッドレス Chromium（iPhone縦・砂1885粒・振動中）の実測でおよそ 59fps。

## 既知の制約

- **音は最初のタップ後に鳴ります。** iOS の制約で、`pointerdown` で AudioContext を resume するまで無音です。
  マナーモード（消音スイッチ）中の iPhone では Web Audio の音は鳴りません。
- **砂は板のローカル座標で保持**しているため、画面回転や板のサイズ変更をしても模様は保たれますが、
  粒子の上限が縮む方向のリサイズ（大きい画面 → 小さい画面）では、あふれた分の粒が消えます。
- 三角形の板は外接円の半径で描くため、正方形・円形にくらべて面積が小さく見えます。
  そのぶん板の下の空きが広く見えますが、器具としては正しい配置です。
- 板を軽くこすっても「完成」表示（板の光）がすぐ戻ることがあります。
  こすった範囲の砂しか散っていない場合は、模様全体はまだ節線の上に乗っているためです。
  全体を崩したいときは強くこすり続けるか、ノブ・ソケット・板を変えてください。
- 砂が少ないうちは模様が点線のようにまばらに見えます。板が大きい端末ほど顕著なので、
  はっきりした模様を見たいときは砂入れを数秒押しっぱなしにして砂を足してください
  （1タップ約60〜80粒、押しっぱなしで毎秒およそ150粒）。
- 二本目以降の指は無視します（一本指専用）。マルチタッチのピンチズームは抑止しています。
- Chladni 図形は物理シミュレーションではなく、見た目のための近似式です。
  実際の板の共振周波数とノブの目盛りは対応していません。
- 砂は「足す」ことはできますが、こぼれた砂は戻ってきません（砂入れの砂は無限です）。
