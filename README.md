# Sweet Towers（ケーキ建築とジャンボパフェ）

4歳児が iPhone / iPad で、縦でも横でも、一本指だけで遊べる「お菓子の建築」ゲーム集です。
文字・矢印・ボタンは一切ありません。世界の「未完成」そのものが次の一手を誘います。

`index.html` をブラウザで開くだけで動きます（依存ライブラリなし、Canvas 2D）。
開始画面ではテーブルにスポンジと空のグラスが並び、触った方のゲームが始まります。

- `engine.js` 共通エンジン（行列、合成音、トゥイーン、トレイ、カメラ、入力、ノード木）
- `cake.js` ケーキ建築、`parfait.js` ジャンボパフェ、`start.js` 開始シーン

## ジャンボパフェ

建築中はクリーム色の背景にグラスがあるだけ。最後にカメラが引くと、ビル屋上の巨大な看板パフェだったと分かり、もう一度触ると夜になってネオンが点きます。グラスの中の層は見せたまま、縁から突き出た足場だけをホイップで隠します。

| 段 | 見える未完成 | 一本指の操作 | 世界の変化 |
|---|---|---|---|
| 1 土台 | 空のグラスとコーンフレークの箱 | 箱を長押しで注ぐ、離すと止まる（高さは自由） | フレークが積もる |
| 2 果物 | 放り込んだ果物が底で転がり続ける | 果物をつまんで放る（叩くだけでも飛ぶ） | ゼリーが注がれ、固まって「プルン」 |
| 3 クッキー | 置いたクッキーが縁に届かず傾く | クッキーを置き、ポッキーを内壁の受けとクッキー端へ | 支柱が「カチッ」、水平になる |
| 4 ソフトクリーム | 絞り口がくるくる誘う | 指で円を描くほど伸び、縁を越えると傾く。ウエハース棒を立てる | 棒で止まる |
| 5 チョコの板 | 一枚目が刺さって「やじろべえ」で傾く | 二枚目を反対側へドラッグ | 釣り合って「カコン」 |
| 仕上げ | 縁の上に棒や板の根元がむき出し | 絞り袋で色を選び、なでる | ホイップの渦巻きに変身 |
| 飾り | トッピングの器 | 叩いた場所に果物や星 | 5個でさくらんぼがパラシュートで降りる |
| 完成 | さくらんぼ | 叩いて落とす | 看板とビルと街へ引く。もう一度叩くと夜、ネオン点灯、開始画面へ |

## ケーキ建築

### 遊びの連鎖（説明なしで進む）

| 段 | 見える未完成 | 一本指の操作 | 支持構造 / 接続方向 |
|---|---|---|---|
| 1 土台 | グラグラ揺れるスポンジ、上面に穴 | ダボを穴へドラッグ（穴を叩いても飛んでいく） | 縦ダボ ×3（上から挿す）→ 揺れが1本ごとに減る → ボードを載せる |
| 2 二段目 | クレーンが下ろした背の高いゼリー状の段が震える | 頭がバウンドする中心棒を連打 / 長押し | 中心棒を上から貫通（叩くほど震えが止まる） |
| 3 スラブ | 風船で浮く長い板。好きな位置に置ける | 横にドラッグして離す → 風船が割れて落下、両端が垂れる | 斜めの支柱を側面ソケットへ（置いた位置で角度が変わる） |
| 4 ボール | 串が立ち、板の端で転がりそうな球 | 球をつまんで放す → 弧を描いて串に「シュッ」 | 串に上から通す（積む順番は子どもの自由） |
| 5 尖塔 | 風船に吊られた円錐 → 割ると乗るが大きく傾く | ウインチを長押し（連打でも可）→ 傾きが連続的に戻る | 張力ロープ（斜め引き） |
| 仕上げ | 工事現場のような内部構造がむき出し | バケツに触れて色を選び、指でなでる | クリームが構造を隠す。支柱はキャンディ柱に変身 |
| 飾り | 空のケーキ、トッピングの器 | 叩いた場所に果物や星が乗る | 5個乗るとろうそくが降りてくる |
| 完成 | ろうそくの芯が火花を散らす | 芯を叩く → 点火 | カメラが大きく引き、部屋と小さな子どもと比べて巨大さが分かる。炎を叩いて吹き消すと新しい一日が始まる |

## 設計方針

- 部品と穴の形状対応、揺れの減少、垂れの回復など、物理的因果だけで次の行動を誘う
- どの操作でも必ず成功する（タップだけでも進める保険を各段に用意）。残るのは板の位置、球の順番、色、飾りの位置という子どもの個性
- 縦は下部に補給トレイ、横は左に補給トレイという専用構図。回転しても継続
- 音は Web Audio で合成（外部ファイルなし）。DPR は 2 でキャップ、パーティクル上限あり

## 自動試遊

`window.__game` に状態と当たり判定の座標を出すデバッグ API があり、Playwright で縦横両方・両ゲームの全工程（開始画面から完成、開始画面へ戻るまで）を一本指ジェスチャーだけで通せることを確認しています。
