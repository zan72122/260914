# シュポッ！ミルクライン

4歳児向け・一本指・文字なしで遊べる搾乳ごっこの Web ゲームです。iPhone / iPad の縦横どちらでも遊べます。

## 遊び方（説明は不要です。世界が誘います）

1. 乳房の下で 4 本の乳頭がゆれ、時々「ぽたっ」と一滴。下のラックには 4 本のティートカップ。
2. カップ（本体か下のホース）を指で上へ持ち上げると、空いている乳頭が光り、近づくと磁石のように吸い寄せられて「シュポッ」。
3. 4 本そろうと透明ホースを白い牛乳が流れ、合流部を通ってジャーへ。
4. 流れが弱くなったカップから 1 本ずつ「シュッ」と外れてラックへ戻り、ジャーが満杯になるとお祝い。
5. しばらくすると次の牛（模様・乳頭の位置・流量・離脱順が毎回違う）がやって来て、また最初から。

## 操作の工夫

- 一本指のドラッグ／タップのみ。多少ずれても最寄りの空いた乳頭へ自動補正され、失敗や行き詰まりはありません。
- 掴んだカップは指より上に表示され、乳頭やカップ先端が指で隠れません。
- 縦画面: 乳房→乳頭→カップ→ホース→合流→ジャーの上下構造。横画面: 牛全体から床のミルクラインまで一続きの世界。

## 起動

静的ファイルのみです（外部アセットなし、音は WebAudio で合成）。

```
python3 -m http.server 8000
```

ブラウザで `http://localhost:8000/` を開きます。ホーム画面に追加すると全画面で遊べます。
