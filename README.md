# ポッポーとおうちへ

4歳児向けの、文字を一切使わない Railbound 風「線路つなぎパズル」。iPhone / iPad の Safari で動く単一ページの PWA です。
設計プランは [docs/01.md](docs/01.md)、実装メモは [docs/02.md](docs/02.md)。

## 遊び方（大人向けメモ。ゲーム内に説明はありません）

- 砂色のマスをタップすると線路が生えます。もう一度タップすると形が変わり、最後に消えます。
- 点線で点滅しているマスが「次に線路が必要な場所」です。
- 客車（犬）から機関車まで線路がつながると線路が光り、機関車が大きく揺れます。
- 機関車をタップすると発車。犬の首輪の色（赤●・青■・黄▲）の順に機関車の後ろへ連結できればクリア。
- 失敗しても巻き戻るだけ。線路はそのまま残るので、直したいマスだけ触り直せます。
- 右上の家アイコンで地図に戻ります。地図では、機関車が煙を吐いている駅が次の面です。

## 動かし方

依存パッケージはありません。静的ファイルを配信するだけです。

```sh
npm run serve          # http://localhost:8080/ で配信（python3 -m http.server）
```

iPhone / iPad から同じ LAN の `http://<PCのIP>:8080/` を開き、共有メニューの「ホーム画面に追加」で全画面になります。
Service Worker により、一度開けばオフラインでも動きます。

## 開発

```sh
npm test               # シミュレーションと全レベルの検証（node --test）
npm run solve          # 各レベルの解の個数をソルバーで表示（-v で解を列挙）
npm run shots          # Playwright + Chromium で iPhone/iPad 縦横のスクリーンショット（要 npm run serve）
node tools/make-icons.js   # アイコン PNG の再生成（要 npm run serve）
```

構成:

- `src/sim/` — DOM 非依存の純粋ロジック（線路モデル・決定的な走行シミュレーション・ソルバー）
- `src/render/` — Canvas 描画（盤面、列車と犬、演出、地図）
- `src/levels.js` — 15 面の定義（テキスト形式）
- `src/main.js` — 画面遷移、入力、再生・巻き戻し・出発の演出
