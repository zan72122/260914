# はなばたけのモンスター

GNOG 風の「さわって遊ぶおもちゃ箱」。箱型モンスター「ハナ」の頭の中はお花畑。
文字は一切出ません。世界そのものが次の行動を招きます。

- 対象: iPhone / iPad の Safari(縦・横どちらでも)
- 技術: Three.js + Vite、Web Audio(音声ファイルなし)
- 計画: [docs/01.md](docs/01.md)

## 動かし方

```sh
npm install
npm run dev
```

同じ Wi-Fi の iPhone / iPad から、表示された `http://<PCのIP>:5173/` を開きます。

## 遊び方(文字で書くとこうなる、というだけ。画面には出ません)

1. ふたの取っ手を上に引く
2. じょうろを鉢の上へ運んで水をやる
3. 箱を横にスワイプして空の面へ。雲の紐を下に引く
4. 花壇へ戻り、蕾をタップ
5. 木の面へ。蛹をタップ
6. 蝶が花に集まって完成。そのあとも全部さわれる
