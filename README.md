# すいすい！床のひみつ探検

4さい向けの、掃除機で床のゴミを吸うだけのブラウザゲームです。
iPhone / iPad の Safari で、指1本だけで遊びます。文字も数字もボタンもありません。

## 概要

このゲームの主役は「ゴミが吸い込まれる**直前**」です。触れたら消える、では
ありません。ノズルが近づくにつれて、ホコリの毛は手前側だけがなびき、パンくずは
ツルツルの床の上で震えてから滑り出し、紙くずはめくれて舞い上がり、砂の山は真ん中
から崩れてすり鉢になり、じゅうたんの毛は一斉に口へおじぎをします。反応はすべて
「ノズルとの距離」だけで連続的に強くなり、そのまま吸い込まれて、透明なチューブを
通って透明なダストカップに溜まっていきます。掃除機をほうきやモップに置き換えたら
成立しない動き ——「吸うから起きること」だけを集めた13の部屋でできています。

部屋は**廊下**でつながっています。廊下にはドアが13枚並んでいて、まだ汚れている
部屋のドアの下からはホコリの玉がはみ出して、ひとりでに揺れています。それを吸うと
ドアが開いてその部屋が始まり、部屋がきれいになるとヘッドは同じドアから廊下へ
戻ってきます。掃除の済んだドアは明るく光り、足元の床がつやつやになります。順番は
決まっていません（最初の1部屋だけが開いていて、それが終わると残りが一斉に開きます）。

得点もタイマーもゲームオーバーもありません。進み具合を表しているのは、溜まって
いくダストカップだけです。そのカップには**限りがあります**。8割を超えると吸引が
目に見えて弱くなり（モーターが低くうなり、毛のなびきが鈍くなり、カップの中身が
フタを押し上げてはみ出します）、満杯になると何も入らず、ゴミは口の前で跳ね返されます。
どの部屋にも、そして廊下にも、小さなゴミ箱が置いてあります。ヘッドをゴミ箱に
近づけるとカップの底が開いて中身がザーッと一度に落ち、フタがパタンと閉じて、
吸引が戻ります。文字での説明はありません。弱くなる → ゴミ箱に寄る → 直る、という
因果そのものが教え役です。

部屋がきれいになると、カメラが動いたり、扉の光が届いたり、おもちゃがどいたり、
床の模様が現れたりして、次に行く場所が世界のほうから見えてきます。全部の部屋が
終わると家じゅうが明るくなり、最後にもう一度ゴミ箱へ大きく空けて、また汚れた
廊下から始まります（進み具合はページを開き直すたびにまっさらです）。

## 遊び方

指1本だけ。タップ、押しっぱなし、なぞる、こする、ぐるぐる回す。
ピンチも2本指も使いません。説明は一切出ません。

- 画面を指でなぞると、掃除機のヘッドが**指より少し先**について来ます
  （指で「吸う瞬間」が隠れないため）。本体はホースでゆっくり後からついてきます。
- **押したまま止まっている**と吸引が強くなります（モーターの音が高くなり、
  まわりの毛が強くなびきます）。教えません。偶然見つかります。
- **廊下**では、ドアの下からはみ出して揺れているホコリにヘッドを当てると、
  そのドアが開いて部屋に入ります。部屋が終わると自動で廊下に戻ります。
- カップがいっぱいで吸えなくなったら、ヘッドを部屋の**ゴミ箱**に近づけます。
  ゴミ箱はどの部屋にも必ず、指の届くところに置いてあります。

| 部屋 | 床・空間 | ゴミの動き方 | この部屋が教えること |
|------|----------|--------------|----------------------|
| 1. 玄関の板の間 (`intro`) | 木の床 | ホコリの玉：手前の毛だけがなびく → 伸びる → ポン | 近づくほど反応が強くなる、という全部 |
| 2. キッチン (`kitchen`) | ツルツルのタイル | パンくず・お米：震える → 滑り出す → 加速 | 通り過ぎると行き過ぎる。床の模様が出てくる |
| 3. 紙くず (`paper`) | ラグと本棚 | 紙：めくれる、舞う、横風で逃げる | 近づく「向き」が大事。押したままが効く |
| 4. おもちゃ部屋 (`toy`) | プレイマット | 大きいおもちゃは吸えない。押してどかすと下から巣が出る | 吸えないものは「押す」。隠れているものがある |
| 5. 糸と髪の毛 (`thread`) | 板の間 | 端から「しゅるしゅる」と、チューブの中を走る | 長いものは端から入る |
| 6. 砂・玄関たたき (`sand`) | 三和土とマット | 山：真ん中を吸うと周りが崩れてすり鉢になる | かたまりは崩れる。下から模様が出る |
| 7. ソファの下 (`sofa`) | 暗がり | 暗闇の中、ヘッドライトに照らされたホコリ | 暗いところにこそ大物がいる |
| 8. じゅうたん (`carpet`) | 深い毛足 | 毛に埋もれて吸えない。こすってブラシで掻き出す | こする、という別の動き。色が戻る |
| 9. 食品庫 (`pantry`) | 黒いタイル | こぼれた小麦粉：筋になって流れ込み、速く動くと舞い上がり、押したままだと穴が掘れる | 急ぐと散らかる、待つと集まる。空気そのものが見える |
| 10. 階段 (`stairs`) | 段板と蹴込み | 段の角のシリアルやビンの王冠：ぐらつく → 落ちる → 弾みながら転がってくる | 重力が手伝ってくれる。壁に押し付けると一段のぼる |
| 11. 窓ぎわ (`window`) | 板の間とカーテン | カーテンの裾がめくれ上がって下のホコリが出る。本棚の裏の細いすき間からは、物が一列で飛び出す | 覆いをどかす。細いところでは口の形が変わる |
| 12. ベランダ (`veranda`) | タイルと落ち葉 | 乾いた葉は口元で割れて砕け散り、濡れた葉は重くて、押したままで端からめくる | 同じ葉でも乾き具合で別物。下から排水口の模様が出る |
| 13. こども部屋 (`bedroom`) | ラグとベッドの下 | クッションの布が口に吸い寄せられ、織り目から毛が抜けて流れる。ベッドの下には大きすぎて吸えないホコリの主 | 大物は一度に取れない。少しずつむしって細らせる |

最後の部屋が終わると家じゅうが明るくなり、廊下がまた汚れて、はじめに戻ります。

## 動作環境

- iPhone / iPad の **Safari**（縦・横どちらでも遊べます。縦と横は別々に
  デザインしてあり、回転しても進み具合は引き継がれます）
- PC のブラウザでも動きます（マウスが指の代わりになります）
- 外部との通信は一切しません。ビルド作業もありません。
- **ホーム画面に追加**すると、全画面のアプリとして起動します
  （Safari で開く → 共有ボタン → 「ホーム画面に追加」）。
- 音は任意です。最初に画面を触った時にだけ鳴り始めます。

## 起動方法

### 手元で動かす

Node.js があれば、付属の小さなサーバーで動きます。

```sh
node dev/serve.mjs      # = npm run serve
```

→ ブラウザで <http://localhost:8080/> を開きます。

`index.html` はリポジトリの一番上にあり、ビルドも依存パッケージもないので、
他のどんな静的サーバーでもそのまま動きます（`python3 -m http.server` など）。

### GitHub Pages で公開する

1. GitHub のリポジトリの **Settings → Pages** を開く
2. **Source** を `Deploy from a branch` にする
3. **Branch** に公開したいブランチ、フォルダに **`/ (root)`** を選ぶ
4. Save

`index.html` がリポジトリの直下にあり、ビルド手順が無いので、これだけで公開
されます。ワークフローファイルも `.nojekyll` も要りません。

## 開発用の仕組み

`dev/` の中身はゲームには含まれません（`index.html` は `src/` しか読みません）。
狙いは「**どの瞬間にも直接入って、1コマずつ見て、同じ入力で再現して、直して、
同じ条件で確かめ直す**」ことです。

### URL パラメータ

| パラメータ | 意味 |
|------------|------|
| `?scene=<id>` | その部屋から始める（`hall intro kitchen paper toy thread sand sofa carpet pantry stairs window veranda bedroom`）。省略すると廊下から始まります |
| `?clean=<id,...>` | 廊下のどのドアが「掃除済み」か（`?scene=hall&clean=intro,kitchen`） |
| `?chain=1` | 廊下を使わず、昔の一本道の順番で遊ぶ |
| `?seed=<n>` | 乱数の種。同じ種なら毎回同じ世界（既定 1337） |
| `?dev=1` | デバッグ表示（ゴミごとの状態と吸引の強さ、ノズル位置、fps、カップの中身） |
| `?speed=<x>` | 時間の倍率。`0.25` でスローモーション |
| `?pose=<portrait\|landscape>` | 表示のみ。実際の向きは画面サイズで決まります |
| `?mute=1` | 音を鳴らさない（撮影スクリプトは必ずこれを付けます） |

例: <http://localhost:8080/?scene=carpet&seed=7&dev=1&speed=0.25>

### `window.game`

```js
game.state()                   // 部屋・掃除機・ゴミ全部の状態（JSONにできる）
game.input.pointer(nx, ny, down)  // 合成タッチ。座標は 0..1 に正規化
game.input.replay(frames)      // [{t, x, y, down}] の台本を再生
game.pause(); game.step(0.1); game.resume()
game.goto('sand')
game.house()                   // 各部屋の掃除済み・保存状態
game.setClean(['intro','kitchen'])  // ドアの状態をその場で変える
game.setSpeed(0.25); game.dev(true)
```

### 「ひとつの瞬間を再現する」レシピ

```sh
# 1. その瞬間に直接入る（部屋 + 種で世界が固定される）
#    http://localhost:8080/?scene=carpet&seed=1337&dev=1

# 2. 普通の入力でそこへ行き、1コマずつ撮る
node dev/shot.mjs --scene=carpet --device=iphone-portrait --seed=1337 \
     --gesture=rub --every=90 --frames=18 --contact

# 3. 退屈なところは飛ばす        --skip=1800
# 4. 面倒な状況は直接作る        --exec="vac.clog = 1"
# 5. 画像ではなく数字を読む      dev/out/<名前>/state.json
# 6. 直したら、同じコマンドをもう一度流して2枚を見比べる
```

`dev/out/<名前>/` に `000.png …` と `state.json`、`--contact` を付ければ
全コマを1枚に並べた `contact.png` が出ます。`--target=<ゴミのid>` や
`--path="0.5,0.8;@crumb,1500"` で、狙ったゴミの**口**が当たる位置に指を運べます。
デバイスは `iphone-portrait` `iphone-landscape` `ipad-portrait` `ipad-landscape`。

### 通し実行

```sh
node dev/playthrough.mjs                    # 4機種すべて
node dev/playthrough.mjs --device=iphone-portrait --from=sand
```

合成の指1本で、廊下から13部屋を最後まで自動で遊びます（ドアのホコリを吸って入り、
部屋を片付け、廊下へ戻り、カップが8割を超えたらゴミ箱へ寄る、までを含みます）。
部屋ごとの所要時間・実測 fps・ページエラー・カップに入った量とゴミ箱に空けた回数を
表に出します。エラーか未クリアがあると終了コードが 0 以外になるので、そのまま
結合テストとして使えます。

```sh
node dev/core-tests.mjs                     # 中核サービスを実ページで検証（33件）
node dev/fps.mjs --scene=pantry --all --seconds=5
```

その他: `dev/sheets.mjs`（全部屋 × 4機種の定番コンタクトシート）、
`dev/carpet-run.mjs` `dev/sand-play.mjs` `dev/sofa-shot.mjs` など部屋ごとの
専用スクリプト。詳しくは `dev/README.md`。

## 構成

```
index.html               全画面キャンバス1枚。これだけで動きます
manifest.webmanifest     ホーム画面に追加したときの名前・色・アイコン
src/main.js              起動、リサイズ、ループ、廊下への出入り、window.game
src/core/                ループ / 数学 / 乱数 / 入力 / カメラ / 音 / 光 / 高さ場 /
                         浮遊粒子 (airborne) / 粉の濃度場 (powder) / 布 (cloth)
src/vacuum/vacuum.js     ノズル・ホース・ダストカップ・airflow の field()・
                         すき間ノズルへの変形・カップの容量と目詰まり
src/debris/              ゴミの種類ごとの動き方（ホコリ、粒、紙、糸、砂、小麦粉、
                         葉、カーテン、抜け毛、ホコリの主…）
src/floors/              床（板、タイル、プレイマット、三和土、じゅうたん、
                         食品庫、階段、窓ぎわ、ベランダ、こども部屋）
src/props/               押せる/押せない家具とおもちゃ、ゴミ箱、蹴込み、本棚、ベッド
src/scenes/              廊下 (hall) と13の部屋。index.js は id と部屋の対応表で、
                         順番は決めません（順番は廊下が持っています）
dev/                     開発用。ゲーム本体からは一切参照されません
docs/BRIEF.md            企画（これが最上位の決まりごと）
docs/PLAN_V2.md          廊下・カップとゴミ箱・新しい5部屋の計画
docs/ARCHITECTURE.md     中身の設計。部屋やゴミを足すときはここから
docs/SCENE_AGENT_GUIDE.md  部屋を1つ書くときの決まり（ファイルの持ち分、ドアの契約）
docs/PLAYTEST.md         「吸い込まれる直前」の検証記録
```

ゴミはすべて `vacuum.field(x, y)` から返る「その点の空気の流れ」だけを見て動きます。
吸引の円や矢印は決して描きません。空気は、世界が動くことでしか見えません。

## 既知の課題

- **実機未検証。** iOS Safari 向けの対策（`viewport-fit=cover`、
  `touch-action: none`、ダブルタップ拡大の抑止、WebAudio の解錠を
  `pointerdown` と `touchend` の両方で行う、バックグラウンド時の停止、DPR は
  2 で頭打ち）はすべて入れてありますが、実機で確かめてはいません。
- **紙くず部屋（横）の最初の1枚**が、掃除機のすぐ手前に置かれているため、
  ひらひら舞う様子が見えないうちに吸い込まれてしまいます（`docs/PLAYTEST.md`）。
- **キッチンのお米**は、白いお米 × 白いタイルでこのゲーム中いちばん
  コントラストが低く、止まっている間は見つけにくいです。
- **じゅうたんと食品庫の部屋は長め**です。じゅうたんは毛を掻き出す面積が広く、
  食品庫は粉を吸い切るのに時間がかかります。通しで遊ぶとこの2部屋だけ長くなります。
- **廊下は平行な壁と奥行きのモヤ**でできていて、遠近法では描いていません。
  奥のドアは小さくなりません。
- 音はまだ控えめで、モーター音と「ポン」「カチッ」くらいしかありません。
- **窓ぎわのすき間の一番小さいパンくず**は 14px と、この5部屋でいちばん小さい
  ゴミです（暗い背景の上で、必ず他のものと一緒に並んでいるので見えてはいます）。
- `docs/PLAYTEST.md` の検証は、前半6部屋 + 新しい5部屋を iPhone の縦横で見たものです。
  `thread` と `sofa`、および iPad の2姿勢は一部の抜き取りしか見ていません。
- **iPad の実測 fps が低め**に出ますが、これは検証コンテナのソフトウェア描画に
  よるものです（`docs/ARCHITECTURE.md` の性能の項）。
