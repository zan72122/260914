# シュッシュッ！ひのこ

4さいのこどものための、**もじのない**火おこしあそび。
ゆびを1本、よこに「シュッシュッ」とうごかすと、木のこなが出て、けむりが立ち、
火種（ひのこ）が生まれます。火種を火口（ほくち）にはこんで、ふうっと息をふきかけると、炎に。

- ステージはこの1つだけ。てんすうも、タイマーも、ゲームオーバーもありません。
- 文字・矢印・ゲージ・チュートリアルは**ゼロ**。せかいそのものが UI です。
- どんなにゆっくりでも、ぐにゃぐにゃでも、かならず火はつきます。

## うごかしかた

```bash
npm start          # http-server をポート 8080 で起動
# → http://localhost:8080 をスマホ／タブレットの Safari で開く
```

ビルドは不要です（素の ES モジュール + Canvas 2D、実行時の依存パッケージなし）。

```bash
npm test           # Playwright で最初から炎まで自動プレイして検証（スクリーンショット付き）
SHOT_DIR=./shots npm test
```

## あそびかた（おとなむけ）

1. 画面のどこでもいいので、ゆびを左右にうごかす → 弓がすべり、弦がきり棒に巻きついてまわる
2. 木のこなが出る → たまる → 茶いろ → こげ茶 → 黒
3. うすいけむり → こいけむり
4. 黒いこなの中に赤い火種
5. 火種ができると、おとなの人がきり棒を持ちあげて火種があらわになる。
   **画面のどこをさわっても**火種がふわりと浮いて指についてくるので、火口（左のふわふわ）へはこぶ
   （とちゅうで手をはなしても、ひとりでに飛んでいきます）
6. 画面をタップ／さわりつづける → おとなの人がふうっと息をふく（3回くらいで炎）
7. 炎になったら、しばらくして画面をさわると、ふわっと最初にもどります

## 設計メモ

- **シグニファイア**: 弓の持ち手は「よこにすべらせる」形（横長カプセル＋すべり止めの溝）。
  さわる前だけ、持ち手にやわらかい光の波紋。何もしないと弓がゆっくり左右にゆれる（不完全さの誘い）。
- **自然な対応づけ**: ゆびが左へ動けば弓も同じ量だけ左へ。きり棒の回転速度＝弓の速度。逆対応なし。
- **因果が目に見える**: 弦は弓の両はしからきり棒へのび、手前で巻きつき、うしろへ抜けて弓へもどる。
  巻きつきの帯の光は回転にあわせてすべり、きり棒にはらせんの帯が2本（止まった絵でも回転がわかる）。
- **見えないレール**: ドラッグは画面のどこから始めてもよく、たての動きは捨てる。ななめ・曲線・ふるえも通る。
- **指でかくれない**: 摩擦点・けむり・火種は画面の上がわ、ゆびを置く弓の列は下がわ。
  火種をはこぶあいだは、火種をゆびより約60px 上に持ちあげて描画。
- **進捗の表示は世界の中だけ**: 木粉の量／黒さ／けむり／火種。ゲージも数字もない。進捗は絶対に減らない。
  だいたい 15〜30 ストロークで火種（4歳児の手で 20〜40 秒）。
- **個性**: 速く擦ると細かい粉が広く散り、ゆっくりだと大きめのフレークが少し。
  板に残る摩擦跡はオフスクリーン canvas に積もるので、毎回すこしちがう絵になる。
- **かならず成功する**: 何度か擦ったあと長く止まってもリセットされず、さらに長く止まればゆっくり前へ進む。
  火種の運搬はマグネット（どこで手をはなしても火口へ／6秒さわらなければ自分で飛ぶ）。
  息ふきは、さわりつづけても、何もしなくても続く。
- **つぎの一手が読める**: 火種が出るときり棒がどけられて火種がむきだしになり、脈打ちながら火の粉を飛ばす。
  火口は同じリズム・同じ色でほのかに光りながらふくらむ（火種と火口を「対」に見せて行き先を示す）。
- **構図は縦横で別**: たては手もとの寄り（顔と手だけが画面に入る）、よこは全身のひざ立ちのひき。
  回転しても進捗・木粉・摩擦跡は保たれます。
- **入力**: Pointer Events、最初の1本のゆびだけ。`touch-action: none`、ピンチ／ダブルタップ拡大／長押しメニューを抑止。
  Canvas は devicePixelRatio（上限2）でサイズ決め、パーティクルは上限つきプール。
- 現実の火おこしの条件（木の種類、乾燥、圧力、速度…）はいっさい教えません。
  のこしたのは「こすれる→こなが出る→黒くなる→けむり→火種→炎」という目に見える因果だけです。
- 音はありません（静かな環境でも遊べるように）。

## ファイル

```
index.html
src/main.js        起動・リサイズ・メインループ
src/state.js       フェーズマシン（drill→ember→carry→blow→flame→リスタート）
src/input.js       1本指・見えないレール・ストローク検出
src/layout.js      たて／よこの構図
src/particles.js   上限つきパーティクル（プール）
src/render/*.js    背景・板・きり棒・弓・火口・人・木粉/けむり/火種/炎
tools/playthrough.mjs  自動通しプレイ（npm test）
```

テスト用に `window.__game`（`phase` / `progress` / `strokeCount` / `layout`、読み取り専用）だけを公開しています。
