# Monument Garden

Monument Valley 風の、文字を一切使わないパズルゲームのプロトタイプ(1面)。
iPhone / iPad の Safari(縦・横どちらでも)でプレイする想定です。

## 遊び方(文字なしで伝わる設計)

- 光る扉が目的地。女の子は道の上をタップした場所へ歩きます。
- 道は途中で切れています。根元に溝のあるオレンジ色のリング(脈打って光る)が「回るもの」の目印。指で左右にドラッグすると塔が回り、90 度ごとにカチッと止まります。
- 道がつながると音が鳴り、扉の光が強くなります。扉まで歩くと扉が開き、紙吹雪。数秒後に自動で最初から遊べます。

## 開発

```
npm install
npm run dev
```

同じ Wi-Fi 上の iPhone から `http://<PCのIP>:5173/` を開くと実機で試せます。

```
npm run build     # dist/ に静的ファイルを出力
npm run preview
```

## 構成

| ファイル | 役割 |
|---|---|
| `src/main.js` | 起動、リサイズ、入力(タップ/ドラッグ)、ゲーム進行 |
| `src/scene.js` | レンダラー、ライト、正投影カメラと画面フィット、配色 |
| `src/level.js` | ステージ定義(グリッド座標)と回転時の接続計算 |
| `src/pathfinding.js` | BFS 経路探索 |
| `src/tower.js` | 回転塔とハンドル、スナップ |
| `src/character.js` | 女の子のモデルと歩行アニメ |
| `src/effects.js` | 扉、光、紙吹雪 |
| `src/audio.js` | Web Audio による効果音の合成 |
