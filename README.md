# Monument Garden

Monument Valley 風の、文字を一切使わないパズルゲーム(全 6 面)。
iPhone / iPad の Safari(縦・横どちらでも)でプレイする想定です。

## 遊び方(文字なしで伝わる設計)

- 光る扉が目的地。女の子は道の上をタップした場所へ歩きます。
- 道は途中で切れています。オレンジ色に脈打つものが「触れるもの」の目印です。
  - 溝のあるリング: 左右にドラッグすると塔が回り、90 度ごとにカチッと止まります。
  - 丸い取っ手: 引く向きにドラッグすると引き出しが滑り出て橋になります。
  - 丸い床: 女の子が乗ると、遠くの階段がせり上がります。
- 夕方以降の面では、高さの違う道でも「画面上でつながって見えれば」歩けます(ペンローズ階段の錯視)。
- 道がつながると音が鳴り、扉の光が強くなります。扉に入ると紙吹雪、建物が沈んで次の面がせり上がります。
- 約 8 秒操作がないと、次に触るものが強く光り、女の子がそちらを見ます。
- 進んだ面は保存され、次に開いたときはその面から始まります。6 面の扉に入ると 1 面へ戻ります。

## 面の構成

| 面 | 時間帯 | 仕掛け |
|---|---|---|
| 1 | 朝 | 回転塔 |
| 2 | 朝〜昼 | 引き出しブロック |
| 3 | 昼 | スイッチ床 → 階段がせり上がる |
| 4 | 夕 | 回転塔 + 錯視 |
| 5 | 夕〜夜 | 引き出し → 回転塔 |
| 6 | 夜(星と提灯) | スイッチ床 → 回転塔 + 錯視 |

## 開発

```
npm install
npm run dev
```

同じ Wi-Fi 上の iPhone から `http://<PCのIP>:5173/` を開くと実機で試せます。

```
npm run build     # dist/ に静的ファイルを出力
npm run preview
```

## 構成

| ファイル | 役割 |
|---|---|
| `src/main.js` | 起動、入力(タップ/ドラッグ)、ゲーム進行、面の切り替え、ヒント |
| `src/levels/index.js` | 6 面のデータ(セル、仕掛け、空の色) |
| `src/build.js` | 面のデータから建物・扉・飾りを組み立てる |
| `src/engine/graph.js` | 高さ・階段・錯視を考慮した歩行グラフと BFS |
| `src/engine/parts.js` | ブロック・道・階段の共通ジオメトリ |
| `src/gadgets/rotator.js` | 回転塔 |
| `src/gadgets/slider.js` | 引き出しブロック |
| `src/gadgets/switchFloor.js` | スイッチ床とせり上がる階段 |
| `src/scene.js` | レンダラー、ライト、正投影カメラと画面フィット、配色 |
| `src/sky.js` | 面ごとの空の色の補間、星 |
| `src/character.js` | 女の子のモデルと歩行アニメ |
| `src/effects.js` | 扉、光、紙吹雪 |
| `src/audio.js` | Web Audio による効果音の合成 |
| `src/progress.js` | 進捗の保存(localStorage) |
