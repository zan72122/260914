# Cake Tower（ケーキ建築）

4歳児が iPhone / iPad で、縦でも横でも、一本指だけで遊べる「ケーキ建築」ゲームです。
文字・矢印・ボタンは一切ありません。世界の「未完成」そのものが次の一手を誘います。

`index.html` をブラウザで開くだけで動きます（依存ライブラリなし、Canvas 2D、単一 JS ファイル）。

## 遊びの連鎖（説明なしで進む）

| 段 | 見える未完成 | 一本指の操作 | 支持構造 / 接続方向 |
|---|---|---|---|
| 1 土台 | グラグラ揺れるスポンジ、上面に穴 | ダボを穴へドラッグ（穴を叩いても飛んでいく） | 縦ダボ ×3（上から挿す）→ 揺れが1本ごとに減る → ボードを載せる |
| 2 二段目 | クレーンが下ろした背の高いゼリー状の段が震える | 頭がバウンドする中心棒を連打 / 長押し | 中心棒を上から貫通（叩くほど震えが止まる） |
| 3 スラブ | 風船で浮く長い板。好きな位置に置ける | 横にドラッグして離す → 風船が割れて落下、両端が垂れる | 斜めの支柱を側面ソケットへ（置いた位置で角度が変わる） |
| 4 ボール | 串が立ち、板の端で転がりそうな球 | 球をつまんで放す → 弧を描いて串に「シュッ」 | 串に上から通す（積む順番は子どもの自由） |
| 5 尖塔 | 風船に吊られた円錐 → 割ると乗るが大きく傾く | ウインチを長押し（連打でも可）→ 傾きが連続的に戻る | 張力ロープ（斜め引き） |
| 仕上げ | 工事現場のような内部構造がむき出し | バケツに触れて色を選び、指でなでる | クリームが構造を隠す。支柱はキャンディ柱に変身 |
| 飾り | 空のケーキ、トッピングの器 | 叩いた場所に果物や星が乗る | 5個乗るとろうそくが降りてくる |
| 完成 | ろうそくの芯が火花を散らす | 芯を叩く → 点火 | カメラが大きく引き、部屋と小さな子どもと比べて巨大さが分かる。炎を叩いて吹き消すと新しい一日が始まる |

## 設計方針

- 部品と穴の形状対応、揺れの減少、垂れの回復など、物理的因果だけで次の行動を誘う
- どの操作でも必ず成功する（タップだけでも進める保険を各段に用意）。残るのは板の位置、球の順番、色、飾りの位置という子どもの個性
- 縦は下部に補給トレイ、横は左に補給トレイという専用構図。回転しても継続
- 音は Web Audio で合成（外部ファイルなし）。DPR は 2 でキャップ、パーティクル上限あり

## 自動試遊

`window.__game` に状態と当たり判定の座標を出すデバッグ API があり、Playwright で縦横両方の全工程を一本指ジェスチャーだけで通せることを確認しています。
