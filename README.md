# フワとイチゴ

黄色い毛玉「フワ」が、とられたイチゴを追いかける、文字のない小さなアドベンチャーゲームです。
iPhone / iPad の縦画面・横画面どちらでも遊べます。画面に文字・ボタン・矢印は一切ありません。触ると必ず何かが起きます。

## 遊び方（おとなの方へ）

1. `index.html` を Web サーバーで公開して Safari で開きます（GitHub Pages なら Settings → Pages → Branch を選ぶだけ）。
2. Safari の共有メニューから「ホーム画面に追加」すると、全画面で起動しオフラインでも遊べます。
3. 最初に画面をどこかタップすると音が出て物語が始まります。途中で閉じても、続きから始まります。

## シーン構成

1. イチゴがとられた（ポンプをタップして風船をふくらませる）
2. 口を開けたカエル（赤い実を落として橋にする）
3. ねむるクマ（おなかをなぞってくすぐる。タップでも少しずつ笑う）
4. チョウチョとお花（葉をめくり、同じ色のつぼみへチョウを運ぶ）
5. ふくらむタンポポ（長押しでふくらませて跳ぶ。タップでも少しずつふくらむ）
6. ニョロつかまえ（穴から出たら叩く）とエンディング

なぞる・長押しが必要な場面でも、タップだけで必ず進めます。同じ物を2回タップすると、フワが自分で手本を見せます。

## 開発メモ

- 依存ライブラリなし。`index.html` 1 ファイルに描画（Canvas 2D）・音（Web Audio 合成）・進行が入っています。
- `manifest.json` と `sw.js` はホーム画面追加とオフライン動作のためのものです。
- `icon.png` はアプリアイコンです。
