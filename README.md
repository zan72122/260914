# うんどうかい — 校庭そのものがメニュー

4歳児向け、iPhone / iPad（縦横）で遊べる日本の小学校の運動会ゲーム。
`index.html` を開くだけで動きます（外部依存なし・Canvas 2D）。

- 校庭を見ること＝メインメニュー。競技一覧やボタン、文字、矢印はありません。
- 触れるのは共有物だけ：紅白玉 / 大玉 / 長棒 / バトン / 綱。子どもたちはそれに追従します。
- 一本指のみ。多少外れた操作は補正され、失敗はありません。
- 縦横で別構図。回転しても競技の状態は保持されます。

ローカル確認: `python3 -m http.server 8765` → `http://localhost:8765/`
