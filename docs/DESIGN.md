# 『あめ！とりこめ！』 設計仕様書（統制文書）

対象: 4歳女児 / iPhone・iPad / モバイルSafari / 縦横両対応 / Wordless。
テーマ限定: 「ベランダに干した乾いた洗濯物が雨に降られ始めたので、濡れる前に室内へ取り込む」。
洗濯機・洗剤・干す・畳む工程は **扱わない**。

## 0. 絶対原則（Wordless Interaction）
- 文章・チュートリアル・矢印・「次へ」ボタン・数値HUD・「クリア」表示は **一切置かない**。
- 世界そのものが UI。次の操作は以下だけで伝える:
  perceived affordance / salient signifier / familiar physical causality / natural mapping /
  perceptual incompleteness / immediate visual feedback。
- 失敗・時間切れ・ゲームオーバー無し。遅ければ少し濡れるだけ。成功保証。
- 全操作は **一本指**（pointer 1本、マルチタッチは最初の1本のみ採用、2本目は無視）。
- 音は演出であり必須情報ではない。**音を消しても、文字を隠しても**進行できること。

## 1. 技術方針
- ビルド無し。静的ファイルのみ。`index.html` + ES modules (`src/`)。外部依存なし（CDN禁止、オフライン動作）。
- 描画: Canvas 2D 単一キャンバス、devicePixelRatio 対応（上限 2）。
- 布表現: 軽量 2.5D。Verlet ロープ/簡易スプリング + 頂点補間 + `ctx.transform` 分割描画（ストリップ）。完全布物理不要。
- 音: Web Audio API による合成（外部音源ファイルなし）。初回タッチで AudioContext を resume。
- 入力: Pointer Events。`touch-action: none`、ダブルタップズーム/長押し選択/バウンス無効。
- 画面回転・リサイズ: `resize`/`orientationchange` で即再レイアウト。**ゲーム状態は保持**、座標は正規化空間から再計算。
- 中断復帰: `visibilitychange` で pause/resume。復帰時に時間ジャンプによる雨の急進行を抑制（dt clamp）。
- 指遮蔽: ドラッグ中の布は指の位置より **上方（縦）／内側（横）** に見えるようオフセット。ヒット領域は見た目より大きい（最小 64px 相当）。
- ローカルサーバ: `python3 -m http.server` で起動可能。
- テスト: Playwright（`/opt/pw-browsers/chromium`、`executablePath` 指定）。`npm install` は不要な範囲で。`tests/` に配置。

## 2. 空間レイアウト（natural mapping）
正規化空間 (0..1) をベースにレイアウト。**常に「雨の外 → 乾いた内」** の方向が一貫する。

### 縦画面 (portrait)
- 上部 ≈ 55%: 屋外ベランダ（空、雨、物干し竿、洗濯物）。
- 下部 ≈ 45%: 室内（開いたサッシの内側、床、ランドリーバスケット、キャラクター）。
- サッシ（引き違い窓）は境界に位置。開いた状態＝「外と内がつながっている」を見せる。
- 取り込み方向: **下方向**へ動かす。

### 横画面 (landscape)
- 左 ≈ 58%: 屋外。右 ≈ 42%: 室内。
- 取り込み方向: **右方向**へ動かす。
- ※ 実装上は `layout.js` が `world.inDir` (単位ベクトル) と各領域矩形を返し、全要素はこれを参照する。

## 3. 進行フェーズ（状態機械）
```
CALM (0–3s) → FIRST_DROP → SPOT → WIND → RAIN_RAMP → (プレイ継続) → EMPTY_LINE → SASH_CLOSE → AFTER
```
- **CALM**: 穏やか。薄い青空、鳥の声（任意）、洗濯物が微風で揺れる。乾いた明るい色。
- **FIRST_DROP**（約3s）: 窓ガラスに **一滴**（最も磨く箇所）。ぽつ、という単発音。滴がゆっくり伝う。
- **SPOT**: 洗濯物の一枚に **濃色の濡れ跡**が一点、二点と広がる。
- **WIND**: 風が吹き、布が **室内方向**へなびく（風向き＝取り込み方向のヒント。natural mapping）。
- **RAIN_RAMP**: 雨粒が徐々に増加。空が暗くなる。雨音がフェードイン。取り込みの進捗とは独立に強くなるが、**罰は無い**。
- 濡れ: 屋外にある洗濯物は時間に応じて色が濃くなる（wetness 0..1）。取り込んだ時点の wetness に応じてキャラクターが軽い反応（ぶるっ／にこっ）。失敗扱いはしない。
- **EMPTY_LINE**: 最後の一枚を取り込んだ → 空の物干し竿 / 満杯バスケット / 開いたサッシ / 降り続く雨 のみ。雨音は室内まで届く（ややこもった大きめ）。**サッシの把手が微かに光る／揺れる**（salient signifier）。カーテンが室内へなびき雨粒が窓枠に当たる（perceptual incompleteness = 閉めたくなる）。
- **SASH_CLOSE**: 一本指でサッシを閉じる方向へドラッグ。「シャーー……」→ 端で「カチッ」。雨音がローパスで遠ざかる。室内が暖色に。キャラクターが安心する。
- **AFTER**: 静かな室内。バスケットの洗濯物、窓の向こうの雨。何も表示しない。（数秒後に軽く画面をタップすると最初からやり直せる隠し導線を置いてもよいが、表示は一切無し。）

## 4. 洗濯物 5 種（別々の操作感・布挙動・音）
全て「意図を一本指で表現 → キャラクターが手作業を補完」。共通コア: **パチン（拘束解除） → バサッ（解放/風受け） → 室内へ**。
各アイテムは `src/items/*.js` に分離し、共通インターフェース `Item` を実装する:
```
class Item {
  constructor(world, spec)
  layout(world)                 // 回転・リサイズ時
  hitTest(x, y) -> boolean      // 見た目より広い判定
  onPointerDown(p) / onPointerMove(p) / onPointerUp(p)
  update(dt, wind, rain)        // 物理・濡れ
  draw(ctx, world)              // 屋外側
  get state: 'HANGING' | 'RELEASING' | 'CARRYING' | 'IN_BASKET'
  wetness: number 0..1
}
```
被る操作は `input.js` が **一本指**として抽象化し、Item へ渡す。

| # | アイテム | 拘束 | 一本指操作 → 感触 | 布挙動 | 音 |
|---|---|---|---|---|---|
| 1 | 二点留めタオル | 洗濯ばさみ ×2 | 室内方向へ **軽く引く**。閾値でばさみが順に外れる（片方→もう片方）。片方外れると **斜めに垂れる**（perceptual incompleteness → もう一回引きたくなる） | 上辺2点固定の Verlet 布ストリップ。片側解放で回転して垂れ、両側解放で落下→キャラがキャッチ | パチン ×2（高め・短い）、ふさっ |
| 2 | ハンガー付きTシャツ | ハンガーが竿に掛かる | **持ち上げてから**室内方向へ（少し上→内へ、いわば「弧」）。ハンガーの掛かりが外れる瞬間に軽い抜け感 | 肩固定 → ハンガーごと揺れる。ハンガーが外れたら袖がひらひら | カラン（ハンガー金具）、ふわ |
| 3 | 小物ピンチハンガー | 多数のばさみ（靴下・ハンカチ等 6〜8個） | **なぞる／連続タップ**: 指が触れたピンチが次々「パチパチパチ」と外れ小物が落ちる。全部落ちたら本体をスッと内へ（自動でも良い） | 個々の小物が軽く落下し、キャラが受け止める | パチパチパチ（ランダムピッチ連続）、軽い落下音 |
| 4 | 重いズボン | 太いピンチ ×2 + 重み | **長く押し込むように引く**（速度より距離／時間）。重いので追従が遅く、指に遅れてついてくる。ずしっと落ちる | 縦長で慣性大、揺れ周期長。落下時に床でどすん | ぱちっ（低め）、ずしっ、どすん |
| 5 | 巨大シーツ（看板） | 洗濯ばさみ ×4（両端 + 中間2） | 拘束を **一つずつ**外す（各ばさみは大きく目立つ signifier、指で触れる／引くで外れる）。外れるごとに布が風を受けて **大きく膨らみ、画面の一部を覆う**。最後の一つで **バサッと解放**、布が一瞬画面いっぱいに翻り、キャラクターが **抱える**（ぎゅっ） | 上辺4点固定の大きめメッシュ（列 8〜12 × 行 6〜8 の Verlet）。風力を布面積に比例させ、解放された端から膨らむ。描画はストリップ分割 + 明暗で厚みを表現。カメラ寄りに見えるよう最大スケール | パチン（重厚）、ばたばた（風）、バサッ（大）、ぎゅっ |

**「見た目違いの同一ドラッグ」禁止**。上記の入力→解放条件（閾値の種類：距離・持ち上げ・接触列挙・時間／距離・逐次解除）を必ず違わせる。

### 洗濯ばさみの signifier
- 拘束されている箇所（ばさみ・ハンガー掛け）は、**風が吹くたびに小さく揺れて光る**（雨開始後）。
- 触れる前でも「ここが留まっている」と分かる形状（クリップの口、ハンガーのフック）。

## 5. キャラクター
- 小さな子ども／小動物（性別・言語無し）。室内側サッシの近くに立つ。
- 役割: (a) 最初の雨滴で **窓を見上げ、洗濯物を指さす**（誘導。ただし矢印ではなく視線としぐさ）、(b) 解放された布を **受け取り**バスケットへ運ぶ、(c) 終盤、サッシの把手を **見る**、(d) 閉めたら安堵。
- 動きはボーン数個の簡易スプライト（頭・体・両手）。

## 6. 進行表示（世界＝UI）
- 残り: 竿に残る洗濯物。
- 進行: バスケットが膨らみ、布が積み重なる（アイテムごとの色で積層）。
- 数値・バー・アイコン列は **禁止**。

## 7. 入力の詳細
- Pointer down: 全 Item の `hitTest` を **屋外領域**で行い、最も手前を選ぶ。無ければサッシ把手判定（EMPTY_LINE 以降のみ有効。それ以前はサッシは動かない）。
- 一本指のみ。`pointerId` を記録し、他は無視。`pointercancel` はドラッグ中断として安全に戻す。
- 「室内方向」は `world.inDir` との内積で判定。逆方向・横方向へのドラッグは布が伸びるだけで解放しない（誤操作耐性）。
- 指を離した後、解放条件未達なら布はスプリングで元位置へ戻る（即時視覚フィードバック）。
- 解放後は指を離しても自動で室内へ（キャラが受ける）。成功保証。

## 8. 音（Web Audio 合成）
`src/audio.js` に集約。全て合成:
- 雨: ノイズ + バンドパス、強度に応じゲイン／フィルタ。屋内化（サッシ閉）でローパス 600Hz + ゲイン低下。
- 一滴: 短い正弦スイープ + 減衰。
- パチン: 短いノイズバースト + 高域クリック。アイテム別にピッチ/長さ。
- バサッ: ノイズ + エンベロープ（シーツは長く低く）。
- サッシ: ノイズのスライド（移動速度に連動）+ 終端カチッ。
- iOS: 初回 pointerdown で `AudioContext.resume()`。無音でも進行に影響しないこと。

## 10. QA 最重要項目
1. **初見の4歳児が大人の説明なしで、雨に気づき、最初の一枚を取り込めるか。**
   - 判定基準（自動化可能な代理指標）: 開始 3〜8 秒の間に FIRST_DROP → SPOT → WIND が視覚的に起き、風で布が **inDir** 方向へなびき、竿上のアイテムのヒット領域が画面の主要部を占め、屋内方向へ 1 ストロークすると必ず何かが「起きる」（ばさみが外れる or 布が伸びる）。
2. 縦・横 それぞれ iPhone (390×844) / iPad (820×1180) 相当で全 5 種を取り込み、サッシを閉じられる（Playwright でドラッグ列を自動再現）。
3. 回転途中（ドラッグ中含む）で状態が壊れない。
4. `visibilitychange` 復帰で雨が跳ばない。
5. 画面上にテキストが無い（DOM テキスト 0、Canvas に `fillText` を呼ばない）。
6. 音を無効化（AudioContext 生成失敗を模擬）しても進行可能。

## 11. 磨き優先順位（新機能より）
最初の雨滴 → ばさみが外れる感触 → 布が拘束から自由になる瞬間 → 巨大シーツ → 空のベランダ → 最後のサッシ。
