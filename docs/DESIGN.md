# 日常の小さな事件集 — 設計書

4歳児向け・一本指・文字なしのWebゲーム。iPhone / iPad、portrait / landscape 両対応。

## 1. 体験の核

1話 20〜60秒。共通の流れ:

```
何かが起こる → 見るだけで因果が分かる → このままだと何が起きるか予測できる
→ 自然に手を出したくなる → 一本指で介入する → 世界が即座に応答する → 少し可笑しい結末
```

ゲーム世界そのものがUI。矢印・点滅リング・指アイコン・「ここをタップ」・進捗ゲージ・
チェックマーク・「成功!」は使わない。文字も読ませない。

## 2. 各話の内部構造 (フェーズ)

すべてのエピソードは次のフェーズ名を持つ。Dev Modeから任意フェーズに直接入れること。

| phase | 意味 |
|---|---|
| `establish` | 場所と主役が分かる静かな導入 (2〜4秒)。カメラがわずかに寄る等 |
| `action` | プレイヤーが「作る/整える」行為をする。完成すると `foreshadow` へ |
| `foreshadow` | 予兆。雲・風・傾き・振動・水滴・動物の視線。子どもが次を予測できる余白 (3〜6秒) |
| `trouble` | 事件が本格化。介入が可能 |
| `intervene` | (trouble と同時進行) プレイヤーの介入。世界が即応する |
| `resolve` | 事件が収まる。救えた/救えなかった両方の結末を持つ |
| `comic` | コミックビート (0.5〜2秒の間、視線、小さな reversal) |
| `settle` | 余韻。もう一度遊べる状態へ自然に戻る (タップでハブへ、または自動でループ) |

Game Over 禁止。失敗は「見て面白い別の結末」。

## 3. 入力

- 一本指のみ。`pointerdown / pointermove / pointerup` を1本に正規化 (最初のポインタ以外は無視)。
- ヒット判定は大きく (最小 44pt 相当、実質はもっと大きい)。
- ドラッグは「掴んだものが指に吸い付く」感触。離すと重力/慣性で自然に落ち着く。
- タイミング精度を要求しない。速度は要求しない。

## 4. レイアウト (orientation)

単純な拡縮ではなく、各話が `layout(portrait|landscape, w, h)` で構図を返す。
主役物体・危険源・安全な場所・指の移動距離を比率ごとに再設計する。

- portrait: 縦に「危険源(上) → 主役(中) → 安全地帯(下)」が並びやすい
- landscape: 横に「危険源(左/上) → 主役(中) → 安全地帯(右)」など
- 指の移動距離は画面短辺の 25〜60% を目安に収める

`resize` と `orientationchange` で再レイアウト。物体の相対位置は保存して補間する。

## 5. 描画

Canvas 2D。前景・中景・遠景を持ち、カメラの微小移動や物体移動で視差を出す。
極端な広角歪みは避ける。物体には物性 (重さ・柔らかさ・濡れ・風・布・砂・水・雪) を
動きと色の変化で表現する。単純な知育アプリ風のフラット記号にしない。

## 6. 音

短い合成音 (WebAudio、外部アセット不要)。最初のユーザー操作で AudioContext を resume。
音は因果の signifier として使う (雨粒の最初の一滴、風の予兆、猫の足音)。ミュート可能。

## 7. Dev Mode

通常プレイヤーには見えない。URL `?dev=1` または左上を素早く5回タップで表示。
画面端の小さなパネル (文字OK・開発者向け):

- エピソード一覧 → 直接入る
- フェーズ一覧 → 任意フェーズから開始
- イベント即時発生 (雨・風・波・猫ジャンプ・日差し など、エピソードが公開する `devActions`)
- 内部状態表示 (phase, timers, 物体の主要状態, seed)
- seed 固定 → 同じ条件を再現
- portrait / landscape の強制切替 (ビューポートを擬似的に変える)
- 各失敗状態を直接再現 (`devActions` に `fail:*` を含める)

## 8. エピソード

### A. 洗濯物 (laundry)
晴れたベランダ。洗濯物を数枚ドラッグして物干しに干す。少し静かな時間。遠くから雲。
光が暗くなる。一滴 → シャツの当たった部分だけ湿って色が濃くなる。数滴 → 雨。
服を室内 (窓/ドア) へドラッグ。全部救出 → 直後に雨が止む → 雲間から光 → キャラが空を見上げる「今?」の間。
失敗: 濡れた服は重く垂れ、持ち上げるとジャバーッと水が落ちる。

### B. ベッドと猫 (bed-cat)
シーツを指でなでて整える。枕を置く。軽くパンパン (タップ) で完成。0.5〜1秒の余韻。
猫が走ってくる (予兆: 画面端に耳・視線・足音)。ジャンプ → シーツ崩れ → 中央で丸くなる。
猫をどかしてもよい (ドラッグ)。どかすと少しして別の場所 (枕の上など) に戻ってくる。眺めてもよい。

### C. 落ち葉 (leaves)
落ち葉を指で寄せる。集めるほど山が大きくなる。完成。風の予兆: 小さな葉が一枚だけ動く → 数枚 →
風 → 山が散る。再び集められる。散り方自体が面白い (渦・舞い)。

### D. 砂の城と波 (sandcastle)
浜辺。バケツをひっくり返す (ドラッグ→離す) と砂の塔ができる。数個で城。
予兆: 波打ち際が少しずつ近づき、濡れた砂の色が広がる。小さな泡。カニが逃げる。
介入: 指でなぞって砂の土手を作る/城を奥へ引きずる。波が土手に当たって砕ける。
失敗: 大波で城が崩れる。崩れ方が面白い (旗だけ残る、カニが頂上から出てくる)。

### E. 帽子と風 (hat-wind)
公園のベンチ、キャラが帽子をかぶっている。予兆: 草がなびく、タンポポの綿毛が飛ぶ、帽子のつばが持ち上がる。
風 → 帽子が飛ぶ。介入: 帽子をドラッグして頭に戻す/先回りして掴む。
失敗: 帽子が別の物 (犬・案山子・雪だるま・別の人) に引っかかる。かぶった側が満足そうにする。

### F. 雪だるまと日差し (snowman-sun)
雪原。雪玉を転がして(ドラッグ)大きくして積む。帽子と鼻をつける。完成。
予兆: 雲が動き、日が差す。色が暖かくなる。雪だるまの表面が光り、一滴垂れる。
介入: 傘/木陰を雪だるまの上へドラッグ、または雪だるまを木陰へ引きずる。
失敗: 溶けて縮む。帽子がずり落ち、鼻が落ちる。最後に小さな雪玉と帽子だけが残る。

## 9. ハブ

文字なし。各話の「小さな動くジオラマ」がタイルとして並ぶ (portrait: 縦2列、landscape: 横3列)。
タップで入る。各話終了後は自然にハブへ戻る (settle でタップ、または数秒後)。

## 10. 技術

- Vite + TypeScript、依存最小。Canvas 2D。外部画像・音声アセットなし (すべて手続き描画/合成)。
- `src/core/` : loop, input, layout, audio, camera, rng(seed), phase machine, dev panel
- `src/episodes/<id>.ts` : 各話。`import.meta.glob` で自動登録。共通化は薄く、各話固有の動きを優先
- `npm run build` で静的サイト (`dist/`)。GitHub Pages を想定し `base: './'`
- Playwright スクリーンショットで portrait / landscape の各フェーズを確認する検証スクリプト

## 11. 最終品質基準 (各話ごとにチェック)

- 4歳児が説明なしに触り始められるか
- 静止画でも何が起きているかある程度分かるか
- 動画なら因果がさらに明確か
- 「何をすればいい?」ではなく「やりたい」が先に来るか
- 失敗してももう一回見たくなるか
- 大人が見ても小さく笑えるか
