# Halloween Night — ひかっているおうちへ
## 企画・設計書（監督: Fable 5.1 / 実装: Opus 5）

### 0. 絶対原則
1. 対象は 4 歳女児。iPhone / iPad の Safari（ホーム画面に追加でも動く）。
2. 画面上に **文字は一切出さない**（HUD・ボタン・タイトル文字・数字も禁止。`<title>` はブラウザ用なので可）。
3. 操作は **一本指のタップ（＋指を置いたまま動かす程度）** のみ。ピンチ・長押し・複数指・精密操作は不要。
4. **ゲームオーバー・失敗・タイムアウトは存在しない。** 何をしても世界は優しく反応する。
5. 「押すべきボタン」を UI で示さない。**世界そのものが触りたくなる状態**を作る。
   - Never explain an action when the world itself can invite it.
6. 前の操作が次の操作を露出する **自己駆動型の連鎖**。
7. 縦横どちらの画面でも成立する。回転しても壊れない。
8. 上質な 3D。フラットアイコンで済ませない。夜の住宅街の空気（霧、暖かい光、月明かり、落ち葉）を徹底して描く。

### 1. 技術方針
- three.js（npm, 最新安定版）+ Vite。`npm run dev` / `npm run build`（出力 `dist/`）。
- 外部 CDN・外部アセットは使わない（この環境から CDN に到達できない）。**全てのジオメトリ・テクスチャ・音は手続き生成**（three.js primitives、CanvasTexture、WebAudio 合成）。
- 後処理: `three/addons` の `EffectComposer + UnrealBloomPass`（光る家・ランタンの発光に必須）。iPhone 向けに `renderer.setPixelRatio(Math.min(devicePixelRatio, 2))`、影は 1 灯のみ（月光 DirectionalLight）。
- iOS 対策: `viewport-fit=cover`、`touch-action: none`、ダブルタップズーム抑止、`gesturestart` 抑止、`orientationchange`/`resize` で即リサイズ、WebAudio は最初のタッチで unlock、`apple-mobile-web-app-capable`、`manifest.webmanifest`（アイコンは SVG data URL などで生成）。
- 縦横対応: 縦画面ではカメラを少し引き気味・高めに、横画面では標準。常に「今のターゲット（光っている家 or 次の操作対象）」がフレーム内に入るようにカメラが追従する。
- デバッグ用: `window.__game`（状態機械 `state`, `advance()`, `tapAt(worldXYZ)`, `houses`, `girl` など）を公開して Playwright から検証できるようにする。文字は出さないが、`?debug=1` のときだけ console に状態遷移を出す。
- GitHub Pages で公開できるよう `.github/workflows/pages.yml`（build → deploy dist）を用意。`vite.config` の `base: './'`。

### 2. 世界
- 夜。深い藍色の空、星、大きな月（微かに雲がかかる）。地面は薄い霧。
- 緩やかに曲がる一本道（歩道＋車道、街灯はほとんど消えている）に **5 軒の家**（＋出発点の「じぶんのおうち」）。家は色・屋根・飾りが全部違う。
- どの家も最初は暗い。**一軒だけ** Jack-o'-lantern と玄関灯が暖かく光り、ゆっくり脈打つ。
- 主人公: 仮装した女の子（デフォルトは魔女: とんがり帽子・マント・ランタン色の bucket を手に持つ）。カートゥーン調だが陰影とリムライトで立体感を出す。歩き・待機（揺れ）・回転ポーズ・bucket 差し出しのアニメーションは手付け（コードで骨をアニメーション）。
- 装飾（各家に散らす。全部タップ反応あり）: Jack-o'-lantern（大小）、蜘蛛の巣＋蜘蛛、吊り下げ幽霊、コウモリの群れ、骸骨の看板、案山子、落ち葉の山、猫、風車、フェンスの門、風鈴、ろうそく。

### 3. 主鎖（trick-or-treat chain）— 必ず成立させる
状態機械 `FIND → WALK → BELL → OPEN → REVEAL → BUCKET → CANDY → NEXT` を 5 軒ぶん回す。

| # | 世界が誘う状態（露出） | 子どもの操作 | 世界の応答 |
|---|---|---|---|
| 1 FIND | 1 軒だけ光る（ランタン＋玄関灯、脈動、蛍が家へ流れる）。女の子はそちらを向く。 | 地面 or 光る家をタップ | 女の子がそこへ歩く（地面タップは自由歩行。家タップは玄関へ自動で向かう）。 |
| 2 WALK→BELL | 玄関に着くと **doorbell が光り始め**、小さく「ぷるぷる」と揺れ、キラッと光る。カメラが少し寄る。 | doorbell をタップ | ピンポーン。ドアが暖かい光を漏らしながら開く。 |
| 3 OPEN→REVEAL | 住人（各家で違う: おばあちゃん、幽霊、猫、かぼちゃ頭、魔女など）が顔を出す。女の子は逆光でシルエット。女の子の周りにキラキラの輪。 | 女の子をタップ | **costume reveal**: くるっと回ってポーズ、マントが翻り、リムライトが当たる。住人が驚いて喜ぶ（跳ねる・目がハートなど、文字なし）。 |
| 4 REVEAL→BUCKET | bucket がキラキラして小刻みに揺れる。住人は手にお菓子を持って待つ。 | bucket をタップ | 女の子が bucket を前へ差し出す。 |
| 5 BUCKET→CANDY | — | （自動） | candy がぱらぱら落ちて bucket に溜まる（粒が見える、音が鳴る、bucket の中身が増える）。住人が手を振ってドアが閉まる。 |
| 6 CANDY→NEXT | **遠くの次の家が灯る**。カメラが一瞬その家をパンして見せてから戻る。蛍がその方向へ流れる。 | 地面/家をタップ | FIND に戻る。 |

- 5 軒目が終わったら **エンディング**: bucket が満杯で溢れ、月が大きく笑い、コウモリが群れて飛び、全部の家の Jack-o'-lantern が一斉に灯り、女の子はじぶんのおうちの前で座ってお菓子を食べる。空に花火（かぼちゃ型）。タップで花火が上がる。しばらくして、じぶんのおうちの Jack-o'-lantern が瞬いて「もう一回」を誘う（タップで最初から。文字なし）。
- **アトラクタ（無操作時の誘導）**: 8 秒無操作で、今の操作対象の脈動を強める・蛍を集める・女の子がそちらを見る・小さな音を鳴らす。それでも文字は出さない。
- **どこをタップしても何かが起きる**（空→コウモリ、地面→落ち葉が舞う＋歩く、家の壁→窓がちらっと光る）。

### 4. 周辺の一本指遊び（発明してよい。最低 6 種）
例:
- Jack-o'-lantern: タップで顔が変わって笑い声、炎が強くなる。連続タップで色が変わる。
- 蜘蛛の巣: タップで蜘蛛がすーっと降りてきて戻る。巣が揺れて露が光る。
- 吊り下げ幽霊: タップで「ばぁ」と膨らんでくるくる。
- コウモリの群れ: タップで飛び立ち、月の前を横切る。
- 落ち葉の山: タップで葉が舞い、中から猫が出てくる。
- 案山子: タップで帽子が飛んで戻る。
- 猫: タップで鳴いて、女の子について来る。
- 仮装: じぶんのおうちの前に 3 体のマネキン（魔女/幽霊/かぼちゃ/黒猫のうち 3 つ）が仄かに光る。タップするとその仮装に着替える（いつでも戻って着替えられる）。

### 5. 音（WebAudio 合成のみ）
- 環境音: 風、遠くのフクロウ、コオロギ（ループ）。BGM は小さく、短いオルゴール風フレーズをループ（怖くしない）。
- 効果音: 足音、ピンポーン、ドアきしみ、住人の声（ハミング的な音程）、キラキラ、candy が落ちる音（複数ピッチ）、コウモリ、猫、笑い声。全部やさしい音量。

### 6. 受け入れ基準（監督がチェックする）
1. 起動直後、文字ゼロ。光っている家が 1 軒だけ画面内にある（縦・横どちらでも）。
2. 何も知らない状態で「地面タップ→玄関→ベルタップ→女の子タップ→bucket タップ」以外の入力をしなくても、世界の脈動だけで次の操作が分かる。
3. 5 軒すべて回れて、エンディングまで到達し、リスタートできる。
4. 誤タップでも進行が壊れない（進行中の演出中にタップしても状態が矛盾しない）。
5. iPhone 縦（390×844）、iPhone 横、iPad 縦（820×1180）、iPad 横で崩れない。回転しても再描画される。
6. フレームレートが iPhone 実機で 30fps 以上を狙える構成（ドローコールを抑え、影は 1 灯、bloom 解像度は半分）。
7. Playwright（headless chromium, SwiftShader）で `tests/` の自動走破が通る。
