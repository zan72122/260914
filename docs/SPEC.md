# パカッ！とろとろオムライス — 実装仕様（監督者作成）

対象: iPhone / iPad の Safari（ブラウザゲーム）。4歳女児向け。**一本指のみ**。
最重要原則: **Wordless Interaction** — 説明文ではなく世界そのものが次の操作を誘う。
Never explain an action when the world itself can invite it.

## 技術
- ビルド不要: `index.html` + `src/*.js`（ES modules）+ `style.css`。依存ライブラリなし。
- 描画は Canvas 2D 一枚（devicePixelRatio 対応、上限 2）。UI ボタンも Canvas 内に描く（絵アイコンのみ）。
- 入力は Pointer Events。`touch-action: none`、`-webkit-user-select: none`、ダブルタップズーム・長押しコールアウト・ゴムバンドスクロール禁止。
- `100dvh` / `visualViewport` でセーフエリア込みのフルスクリーン。`<meta name="viewport" content="width=device-width, initial-scale=1, viewport-fit=cover, user-scalable=no">`。
- 音は任意（あれば短い効果音のみ、初回タップで AudioContext を解錠）。音声説明に依存しない。
- 状態機械はレイアウト非依存。**画面回転は状態を保持したまま座標系だけ再計算**する。
- 60fps を目標に requestAnimationFrame。流体・軟体物理は不要、見た目の変形とイージングで代用。

## レイアウト
- 縦画面: 上=皿、中央=フライパン（コンロ）、下=道具（ケチャップボトル・ヘラ・卵ボウル）。下→上へ工程が進む。
- 横画面: 左=コンロ+フライパン、右=皿、道具は下辺。左→右へ料理が移る。
- 指の遮蔽: 操作対象の上に指が乗っても結果が見えるよう、変化は指より少し上/外側に強調表示する。
- すべてのヒット領域は最低 44pt、実際は「ざっくり」判定（吸着・補正）。

## 状態機械（各ステートは見た目で次を誘う）
1. `RICE_KETCHUP`  白いご飯（皿）とケチャップボトル。ボトルを**皿の上へドラッグ or 長押し**で赤い線が出る。皿へ近づくとボトルが自動で傾く。ご飯の上に赤が十分（閾値）乗ったら次へ。ボトルは離すと定位置へやわらかく戻る。
2. `RICE_MIX`      ヘラが皿の縁でぴょこぴょこ誘う。皿の上で**ざっくり円運動/ドラッグ**するとその軌跡周辺が白→赤に変わる（塗り率で進行）。8割で全体が一気に赤く整い、**ふくらんだ楕円**にまとまる（自動整形、気持ちよい弾み）。
3. `EGG_POUR`      卵ボウルがフライパン脇で揺れて誘う。ボウルを**フライパンの上へドラッグ or タップ**で黄色い卵液がジュワッと広がる。
4. `EGG_GATHER`    フライパン上で**中央へ向かうスワイプ/ドラッグ**を数回すると、広がった黄色が中央へ寄り、ぷるぷるした半熟オムレツ（楕円の塊）にまとまる。塊は常にわずかに揺れる。
5. `EGG_SLIDE`     皿の赤いライスとフライパンのオムレツが並ぶ。**フライパンを皿側へドラッグ/スワイプ**（またはフライパンをタップ長押し）でフライパンが傾き、オムレツが**スルッ**とライス上へ滑って乗る。着地でライスとオムレツが一緒にぷるんと揺れる（シグネチャー）。誤方向はやわらかく戻る。
6. `CUT`           オムレツの中央に**稜線（ハイライト）**が見える。稜線に沿って**太い一筋のドラッグ**（縦横どちらでも、精度不要、稜線へ吸着）で切れ目が入る。
7. `OPEN`          切った直後 **約0.3秒の間** → **パカッ**（両側が外へ倒れる 0.3秒）→ **トロッ**（とろとろ卵が黄色〜オレンジのグラデで広がりつつ艶が走る 0.5秒）。合計約1秒のシグネチャー演出。操作不可、見せる。
8. `DRAW`          開いた黄色い面が「空白のキャンバス」。ボトルが皿の横で待つ。**指でなぞる**と赤い艶のあるケチャップ線が描ける（太めの線、丸端、ハイライト）。面の外にはみ出しても皿の上まで OK。
9. `DONE_MENU`     描画中いつでも画面隅に**絵だけのボタン**: 🔁「もう一回」（最初から）、✨「別バージョン」（皿の色・ケチャップの色味・卵の焼き色など小さな見た目違いでもう一回）、🖌「自由に描く」（DRAW 面だけリセットして描き直し）。文字なし。

- 各ステートでは「次に触るべきもの」だけが**微かに呼吸/揺れ/艶の反射**で誘う（idle アトラクト）。それ以外の道具は静か。
- 誤操作: ×表示や停止をせず、吸着・補正・やわらかい戻りで成功へ導く。
- 失敗・時間制限・採点・星・注文・お金・レシピ説明は無い。
- テキストは無し（タイトル画面も絵と一回タップで開始、あるいはタイトル自体を省略してもよい）。

## 見た目
- 赤 × 黄の対比、ケチャップの艶（ハイライト線）、卵のぷるぷる（楕円の呼吸アニメ＋着地の減衰揺れ）、とろとろ（開いた後に流れ出す濃い黄〜オレンジ、艶のスペキュラ）。
- 皿は白で縁に淡い模様。木目テーブル背景。フライパンは黒で取っ手あり。ボトルは赤いキャップの半透明ボトル。
- 安っぽい平面 UI や文字中心の画面は禁止。ボタンは絵。

## 検証（Playwright, Chromium）
- iPhone (390x844) と iPad (820x1180) の縦・横で一周通しで自動操作し、各ステートのスクリーンショットを `screenshots/` に保存。
- 途中で画面回転（viewport 変更）しても状態が保持されること。
- 画面切れ、操作不能、ボタンの重なり無し。
