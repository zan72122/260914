## 2. 遊び方の変更点(v1 から)

- 汽車と貨車は**全レベルで手前左**にいる。汽車ループでは線路を走り、格子・オルゴールでは側線に停まって貨車の楽器が拍で跳ねる。側線の右端のトンネルが次への扉。
- **格子の島**: タイルに塔を置く。列 = 拍、行 = 高さ(奥ほど高い)。光の棒が通ると塔が跳ね、タイルが光る。1 列に何個でも(上限 12)。
- **オルゴール台**: 見えている穴にピンを差す。ピンが上端に来ると鍵盤が沈み、鳴る。行(左右) = 高さ。穴は回るので、狙った列より「離した時に一番近い穴」に入る。
- 汽車ループだけ、棒の上下で音程を変える。格子・オルゴールは置く場所が音程。
- 取り消しはどの形式でも「持ち上げて置き先の外で離す」→ トレイへ跳ねて戻る。

## 3. 確認方法

### 自動
```
npm install
npm test          # 単体テスト(時計・レベル生成の形式ルール・保存と v1 移行・配置ルール)
npm run smoke     # Playwright(WebGL / SwiftShader): iPhone 縦・iPad 横で 汽車→格子→オルゴール→汽車→駅→ミュート→新曲 を通す
npm run build     # 型チェック + dist/ 出力
node tests/smoke/shots.mjs <出力先>   # 各形式のスクリーンショットだけ撮る補助
```
スモークテストは `?test` を付けたときだけ有効になる `window.__tt`(3D オブジェクトの画面座標を返す)で操作位置を得て、結果は localStorage の保存内容で検証する。ソフトウェア描画のため 1 本あたり 1〜2 分かかる。

### 実機(利用者)
1. `npm run build` → `dist/` を静的サーバへ(相対パスなのでサブディレクトリでも可)。
2. iPhone / iPad の Safari で開く。ホーム画面に追加すると全画面。
3. チェック観点:
   - [ ] サイレントスイッチが OFF(鳴る側)
   - [ ] 最初のタップで汽笛が鳴り汽車が動く。蒸気が出ている
   - [ ] トレイの楽器を持ち上げると鳴り、置き先が光る。置くと弾んで鳴り、紙吹雪が舞う
   - [ ] 汽車ループ: 棒の上下で音が変わる。横へ外して離すとトレイへ戻る
   - [ ] 格子: 光の棒が通ると塔が跳ねてタイルが光る。1 列に複数置ける
   - [ ] オルゴール: 見えている穴にピンが入り、上端で鍵盤が沈む。裏に回って戻ってくる
   - [ ] 扉を叩くと汽車がトンネルへ入り、楽器が貨車に飛び乗り、次の台へ移る
   - [ ] 駅で貨車を叩くとふたが閉まって静かになる。青い汽車で新曲
   - [ ] 縦↔横に回転しても状態が保たれ、台が画面に収まる
   - [ ] **発熱とフレームレート**(iPad で滑らかか)。重ければ `renderer.ts` の shadow.mapSize を 512 に
   - [ ] v1 で遊んだ端末では、前回の曲が(すべて汽車ループとして)引き継がれる

## 4. 既知の制限・今後

- オルゴールの穴は回っているので、特定の列を狙って差すのは難しい(仕様として受け入れ。行 = 音程は狙える)。
- 縦画面(iPhone)では台の横幅で大きさが決まるため、楽器が小さめ。ヒット判定は見た目より大きい。
- 影は 1024px のシャドウマップ 1 枚。古い iPad で重い場合は 512 に落とす。
- パイプの「光る」表現は共有マテリアルの都合で「太くなる」に置き換えた。
- v2 非ゴール: 合唱隊・ブロックの島、カメラ操作、glTF、カセット、書き出し、アンロック、自動デプロイ。
