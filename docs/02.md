## 1. 新しい円の法則

すべて「触れた瞬間の反応」で分からせる。文字・矢印・アイコンは使わない。

| 法則 | 色 | 見た目のシグニファイア | 振る舞い |
|---|---|---|---|
| **壁** | 灰色 `#C9CCD6`(彩度ゼロ=生き物ではない) | 大きく、影が濃く、呼吸しない。じっとしている | じぶんの円・他の円が当たると少し凹んで「ぷにっ」と押し返す。すり抜け不可。縮んだ円は隙間を通れる |
| **くっつく** | 紫 `#9C4DFF` | 近づくと細い糸のような光が伸び、引き寄せられる | じぶんの円に触れると張り付き、指についてくる(遅れて追従)。輪に入ると離れて輪に収まる |
| **合体** | 青緑 `#00BFA5` | 同色の小さな円が2〜3個。互いに向けて微かに揺れる | 押してぶつけると1つの大きな円になる(面積保存)。合体音。大きな輪に入る |
| **分裂** | 赤 `#FF3B30` | 1つの大きな円に、内部に薄い区切り線(3つに分かれる予感) | じぶんの円が触れると3つの小さな円に弾け、それぞれがじぶんの円について来る(ついてくる法則の再利用)。小さな輪が3つ |

輪の共通ルール(拡張):
- 輪は複数置ける。**全ての輪が満たされたらクリア**。満たされた輪は円が収まったまま残る。
- 輪の `target` は `'player'`、個別 id、または `{ type: 'sticky' }` のように「その種類のどれでも」。
- 輪の色と大きさが「入るべき円」を示す(従来通り)。

## 2. レベル設計(7〜18面)

| # | 法則 | 配置(概要) | 気づき方 |
|---|---|---|---|
| 7 | **壁**(紹介) | 中央に大きな灰の円。輪はその向こう側 | ぶつかると押し返される → 回り込む |
| 8 | 壁 + 縮む | 灰の円が2つ並び、隙間が狭い。手前に水色の円。輪は隙間の向こうで小さい | 通れない → 水色で縮む → 通れる |
| 9 | **くっつく**(紹介) | 紫の円が近くに1つ。輪は紫色で少し離れた場所 | 触ると張り付いてくる → 輪へ運ぶと外れて収まる |
| 10 | くっつく ×2 + 輪 ×2 | 紫の円2つ、紫の輪2つ | 1つずつ運ぶ。複数の輪の導入 |
| 11 | **合体**(紹介) | 青緑の小さな円2つ、大きな青緑の輪1つ | 小さいままでは輪に合わない → 押してぶつけると大きくなる |
| 12 | 合体 ×3 + 壁 | 小さな円3つが壁の周りに散らばる。輪は大きい | 3つ集めて1つに。壁を回り込む |
| 13 | **分裂**(紹介) | 赤い大きな円1つ、小さな赤い輪3つが並ぶ | 触ると3つに分かれてついてくる → 輪の上を通ると1つずつ収まる |
| 14 | 分裂 + 壁の隙間 | 赤い大きな円は隙間を通れない。輪3つは隙間の向こう | 分けてから隙間を通り抜ける |
| 15 | 逃げる + 壁 | ピンクの円が逃げる。壁2つで作った袋小路の奥に輪 | 壁が追い込みを助ける |
| 16 | くっつく + 縮む + 壁 | 紫の円を張り付けたまま、水色で縮めて隙間を通り、小さな紫の輪へ | 水色は張り付いた円も一緒に縮める |
| 17 | 合体 + 押す + 輪 ×2 | 青緑の小さな円4つ → 2組を合体させて2つの輪へ | 同じ法則の繰り返しで達成感 |
| 18 | 分裂 + ついてくる + 壁 + 輪 ×3(フィナーレ) | 赤の円を分けて、黄の円と一緒に壁の間を抜け、輪3つ + 黄の輪1つを埋める | 総まとめ。クリア後は全色の祝福 |

各面は Playwright 自動プレイで「必ず解ける」ことを検証する。行き詰まり(円が壁の裏で詰む等)は、壁との押し返しと「指が遠いと輪の方へ流れる」の組み合わせで防ぐ。

## 3. 星空マップ

- **見た目**: 濃紺の背景 `#101637` に、18個の星が緩やかな曲線(縦は S 字、横は波)で並ぶ。正規化座標で縦横両対応。
  - クリア済みの星: その面の「入るべき円」の色で塗られた小さな円。
  - 未クリアの星: 細い白の空の輪(=まだ何も入っていない)。
  - 最初の未クリアの星: 呼吸して光る(次はここ、と誘う)。
  - 星と星は淡い線で結ばれ、道順が見える。
- **入る**: 星に触れると、その星が膨らんで画面全体をその面の背景色で満たし、面が現れる(現行の場面転換と同じ演出)。
- **出る(クリア時)**: 輪が満たされる → 世界がズームアウトして星空になり、今の面の星が色で満たされる → 約 3 秒後に次の未クリアの星へ自動ズームイン。待ち時間中に別の星に触れればそちらへ。
- **起動時**: 星空から始まり、約 4 秒無操作なら最初の未クリアの星へ自動ズームイン(「星に触れると入る」のデモを兼ねる)。
- 18面全クリア後: 祝福演出ののち星空へ。全ての星が満たされた状態で、どの星にも触れられる。
- 進捗: `localStorage` に「クリア済み面の配列」を保存(旧キー `circles.level` は読み捨て)。

## 4. 実装ステップ

1. **リファクタ**: `js/main.js` から法則の物理を `js/laws.js`、星空を `js/map.js` に分離。輪を配列化し「全て満たされたらクリア」に変更。target の `{type}` 指定に対応。
2. **壁**: 円同士の押し返し(じぶんの円・他の全ての円に適用)、凹み表現、「ぷに」音。
3. **くっつく**: 接触で付着、遅れ追従、輪で分離。糸状の引き寄せ表現。
4. **合体**: 押せる円同士の接触で結合(面積保存)、合体アニメ・音。
5. **分裂**: 接触で3分割、破片はついてくる法則。分割アニメ・音。
6. **7〜18面**の配置と数値調整。
7. **星空マップ**: 描画、タッチ、ズームイン/アウト演出、進捗保存、起動時フロー。
8. **検証**: Playwright 自動プレイを新法則に対応させ、縦(390×844)/横(844×390)/iPad(820×1180)で18面すべてクリアできることと、星空の見た目をスクリーンショットで確認。
