# 02. 実装メモ（プラン 01 の実装結果と差分）

- ステータス: 実装済み（ブランチ `claude/railbound-kids-puzzle`）
- 作成日: 2026-09-13

## プランどおりに実装したもの

- 単一 HTML + Vanilla JS + Canvas 2D の PWA（manifest / Service Worker / アイコン同梱、外部依存なし）
- タップで線路が出現 → 再タップで形が巡回 → 最後に消える。最初の一手は隣接する線路の向きから自動で最適な形を選ぶ
- 機関車タップで発車。失敗時は「ドン」と跳ねて驚いた顔になり、逆再生で元の位置へ戻る（線路は残る）
- 詰まる場所の点線ゴースト、つながったときの線路の光と機関車の揺れ、連結順を示す機関車後部の色タグ（色 + 形で二重符号化）
- Web Audio で合成した効果音（木のコトン、汽笛、ガタンゴトン、カチャン、ポヨン、ファンファーレ）
- 地図型ワールドマップ + localStorage 保存。クリア済みの駅では犬が手を振り、次の駅で機関車が煙を吐いて待つ。未到達の駅は霧
- クリア後は列車が自走して画面外へ去り、地図上で次の駅へ走って到着する
- 15 面。`tests/levels.test.js` で「初期状態は未解決」「保存された解でクリア」「ソルバーが解を見つける」「1〜4, 6 面は解が一意」を検証
- Playwright + Chromium で iPhone / iPad の縦横 4 種のレイアウトを自動確認（`npm run shots`）

## プランからの変更点

### 固定の合流ポイント（Y 字線路）を追加

プランでは「分岐スイッチは含めない」としていたが、線路が 2 方向接続のみだと、別の場所から来る 2 両を同じ機関車につなぐ手段が存在しない（全車両が同一線路上に並ぶ面しか作れない）ことが設計中に判明した。
そこで **プレイヤーが置けない固定の合流ポイント** を導入した。

- 2 本の枝から入った車両は幹へ抜ける。切り替えは起きない（Railbound の「切り替わるスイッチ」は未実装）
- 置けるパーツは従来どおり直線 2 種 + カーブ 4 種のみで、タップ巡回は増えていない
- 同じティックに 2 両が合流点へ入ると衝突。これが 9 面以降の「遠回りで時間差をつける」パズルの核になる

### 連結ルール

Railbound と同様に「列車の最後尾のすぐ後ろに、最後尾と同じ向きで入ってきた車両だけ連結する」。
合流点の別の枝から最後尾へ突っ込むと衝突扱いになる。
