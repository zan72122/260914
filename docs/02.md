# 02. 実装メモ — 01 のプランからの差分と判断

## 実装したもの（01 の M1〜M6 相当）

- 単一 `index.html`（約 700KB、Three.js / cannon-es / レベルデータ / 効果音を全てインライン）。
- ボール3種（しろ / てつ / ばくはつ）、ブロック4種（ふつう / てつ / ガラス / くも）、レベル10。
- 世界そのものを UI にする要素:
  - 足元の台に実物のボールが並ぶ（残数）。台のボールをタップするとパチンコのボールと入れ替わる。
  - パチンコの Y 字とゴム。引くとゴムが伸び、点線の軌跡が出る。
  - 無操作 3 秒でボールがぴょこんと跳ね、6 秒で半透明の指の影が「引いて放す」を1回演じる（発射経験があると以後は跳ねるだけ）。
  - クリア: 光の粒 → 次の塊が上から降りてくる。
  - ボールが尽きる: 消えたブロックが下から浮き上がって元の形に戻り、ボールが左から転がって戻る。
  - 2本指で画面をなでると途中でも巻き戻る。
- Playwright による検証（`npm test`）: 3ビューポートで、DOM に可視テキストが無いこと、ドラッグ→発射でボールと
  ブロックが減ること、台のボールのタップで入れ替わること、撃ち尽くすと clear / rewind へ遷移して play に戻ること。

## プランからの変更点・判断

| 項目 | 01 の記述 | 実装 | 理由 |
|---|---|---|---|
| 塊が浮いている理屈 | 明記なし | 触られていないブロックは凍って（static）浮く。ボールで砕けたブロックの**上に乗っていた**ブロックは支えを失って落ちる。落下中のブロックにこすられた・上に乗られた凍ったブロックも目覚めて落ちる。 | 「下を抜くと上が落ちる」という見れば分かる因果に絞った。横のブロックは直接触れないと落ちないので、狙う意味が残る。 |
| 狙いの写像 | 引いた逆方向へ飛ぶ | 引いた量を塊上の**狙点**に写像し、一定飛行時間で届く初速を逆算（下に引くほど高く、横に引くほど横）。軌跡プレビューも同じ式。 | 4歳が力加減を学ぶ必要が無い。「点線の先に当たる」が常に成立する。 |
| 端末シェイクでリセット | 入れる（推奨） | **入れない**。2本指なでで代替。 | iOS では加速度センサーに文字入りの許可ダイアログが必須で Wordless に反する。 |
| 前のレベルへ戻る導線 | 後回し | 未実装（プラン通り）。 | |
| PWA | meta タグのみ | `apple-mobile-web-app-capable` 等の meta を入れた。Service Worker は無し。 | file:// 起動なので SW は動かない。 |
| ボール足場の配置 | 画面下 | カメラの子要素として固定し、縦横どちらでも画面下中央に来る。アスペクトに応じて奥行きを変え、台が画面幅に収まるようにする。 | 縦横切替で操作の場所が変わらない。 |
| 横画面 | 明記なし | 塊を画面上部（NDC y ≥ -0.08）に寄せて足場との重なりを避ける。 | |

## 調整値（チューニングの起点）

| 項目 | 値 |
|---|---|
| 重力 | -22 |
| 飛行時間（発射→狙点） | 0.62 s（+ 引き量 × 0.05） |
| 引ける最大量 | 画面半高の 24%（カメラ空間） |
| 発射に必要な最小引き量 | 最大量の 15%（未満なら弾力で戻る・キャンセル音） |
| 爆発半径 | 2.4 |
| 上に乗って止まった判定 | 速度 < 0.6 が 0.35 s 続く |
| 巻き戻し開始 | 台も空中も空、かつ動くものが無い状態が 1.2 s |
| 落下物の消滅 | 塊の最下段 − 7 より下、または 9 s 経過 |

## 実機で見てほしい点

1. 引く量に対する軌跡の感触（引き過ぎ/足りない）。
2. 音量バランス（合成音。`src/audio.js` の gain）。
3. 背景と「ふつう」ブロックのコントラスト（レベルごとの色相は `src/levels.js` の `hue`）。
4. くもレベル（7・9）はくもを狙わないと崩れない。4歳に「くもを撃つ」が発見できるか。
