## 2. 遊び方(言葉なしでの想定導線)

1. 汽車が蒸気を吐いて止まっている → どこかを触る → 汽笛が鳴り走り出す。
2. 箱の中の楽器が時々跳ねている → 触ると持ち上がり音が鳴る → 空き穴が光る → 穴に落とすと弾んで鳴る。
3. 汽車が楽器を通るたびに楽器が揺れ、紙吹雪が舞う。
4. 鳥・鈴・木琴・笛・かえるは棒の上に乗る → 上下に動かすと棒が伸び縮みし、高いほど高い音。
5. 楽器を穴の外へ運んで離す → 箱へ跳ねて戻る(取り消し)。
6. 楽器を 1 つでも置くと、トンネルの扉が少し開いて光が漏れる → 叩くと全開 → 汽車が入ると楽器が貨車に飛び乗り、次の場所へ。
7. 4 つ目の場所を抜けると駅に到着。貨車を叩くとふたが閉まり、その層だけ静かになる。
8. 下(横画面では右)で待つ青い汽車を叩くと、今の汽車は去り、新しい曲が始まる。
9. 汽車そのものを叩くと火が大きくなり速くなる(3 段階)。

## 3. 確認方法

### 自動
```
npm install
npm test          # 単体テスト(時計・レベル生成・保存)
npm run smoke     # Playwright: iPhone 縦 / iPad 横で、置く→音程→扉→4 層→駅→新曲 を通す
npm run build     # 型チェック + dist/ 出力
```
スモークテストは操作結果を localStorage の保存内容で検証し、コンソールエラーが無いことも確認する。スクリーンショットは `test-results/shots/` に出る。

### 実機(利用者)
1. `npm run build` で作られる `dist/` を任意の静的サーバに置く(相対パスなのでサブディレクトリでも可)。
2. iPhone / iPad の Safari で開く。ホーム画面に追加すると全画面になる。
3. チェック観点:
   - [ ] 本体のサイレントスイッチが OFF(鳴る側)になっている ※ ON だと Web ページの音は出ない
   - [ ] 最初のタップで汽笛が鳴り、汽車が動く
   - [ ] 楽器を持ち上げた瞬間に音が鳴り、穴が光る
   - [ ] 置いた楽器を汽車が通ると、揺れ・紙吹雪・音が同時に起きる
   - [ ] 棒の上の楽器を上下に動かすと音の高さが変わる
   - [ ] 縦↔横に回転しても配置が保たれる
   - [ ] アプリを閉じて開き直すと続きから始まる(最初のタップの後)
   - [ ] 4 層まで重ねて駅に着く。貨車を叩くと静かになる。青い汽車で新しい曲になる
   - [ ] 2 本指で触っても画面が拡大・スクロールしない

## 4. 既知の制限・今後

- サイレントスイッチはアプリ側で回避できない(iOS の仕様)。
- ローディング画面はないが、Safari がバックグラウンドから復帰した直後は音の再開に 1 タップ必要な場合がある。
- 同じ楽器を複数の穴に置ける(意図どおり)。1 穴 1 楽器。
- v1 非ゴール(プラン 0 章): カセットコレクション、音声書き出し、アンロック、自動デプロイ。
- 音は Chromium で動作確認したのみ。iOS Safari での音色バランスは実機で要確認。
