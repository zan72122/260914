# 02. 実装記録と計画(01)からの変更点

ステータス: **実装済み**(ブランチ `claude/gnog-flower-butterfly-toybox`)

## 計画どおりに実装したもの

- ふたの取っ手を上に引いて開ける(タップだけでも少し持ち上がって「引ける」ことを見せる)
- 面A 花壇: じょうろを鉢の上へ運ぶと傾いて水が出る → 土が湿ってひびが消える → 芽
- 面B 空: 雲の紐を下に引くと雲がどいて太陽 → 世界が明るくなる → 芽が蕾になる
- 面A: 蕾をタップで開花(太陽なしでは揺れるだけ)。3つ咲くと光の粒が木の面へ流れる
- 面C 木: 蛹をタップ → 揺れる → もう一度で割れて蝶 → 花へ飛んでいく
- 完成: ファンファーレ、頭の蕾が開花、花びらが舞う、花壇の面へ自動で戻る。文字は出ない
- おもちゃ箱モード: 花をタップで蝶が集まる、紐を引くたびに 昼→夕焼け→夜→昼、水やりで花が揺れる
- 手詰まり: 次にさわる物が常に軽く脈動。15秒放置で強く脈動+光の粒+ハナがそちらを見る。別の面にあるなら箱がそちらへ揺れる
- 閉じたまま5秒放置でふたがカタカタ
- 音: Web Audio のみ。パッド → アルペジオ(開封) → ベース(芽) → 鈴(太陽) → トリル(開花)。夜はパッドがこもりアルペジオが止まる
- 縦横対応(画面比率でカメラ補間)、iOS Safari のズーム/スクロール抑止、初回タッチで AudioContext 開始

## 計画から変えたこと

| 計画 | 実装 | 理由 |
|---|---|---|
| ふたが開くと中が見える | ふたに加えて**顔のついた前面が前に倒れる**。倒れた面の内側にも顔があり、開くと上を向いてプレイヤーを見る | 前面の壁が残ると、上から覗く角度では床の手前半分(じょうろ)が隠れて掴めなかった |
| 3面を回して切り替える | 同じ。ただし3つのジオラマは箱の内側で**同時に存在**し、正面から見るとお花畑の奥に空(左)と木(右)が見える | 内部が1つの箱なので、面ごとに独立した空間は作れない。結果的に「1つの世界」の一体感が出た |
| 蝶は面Cから面Aへ飛ぶ | 同じ。箱ローカル座標でベジェ曲線を飛ぶ | — |

## 既知の制約

- 横画面(特に iPhone 横)では倒れた顔の下半分が画面外。中身の操作には影響なし
- 開発用に `window.__hana` を公開している(`npm run dev` のときのみ。ビルドには含まれない)

## 動作確認

Chromium(headless、swiftshader)で iPhone 縦/横、iPad 縦/横の4サイズについて
開封 → 水やり → 紐 → 開花 → 蛹 → 完成 → おもちゃ箱(蝶の集合、夜)まで通しで確認済み。
実機 Safari の音・タッチは未確認のため、初回は実機での確認を推奨。
