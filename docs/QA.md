## 描画順の判断（シーツがサッシ枠より前に出る理由）
`Item.overlay` が真のアイテムは `sash.drawFrame` の **後** に描かれる（`main.js`）。シーツは
**ばさみが 2 個以上外れた時点から解放完了まで** これを真にする。理由: その状態のシーツは
開いた窓を通って室内側へ実際に膨らみ出しており、「ガラスの向こう」ではなく
「カメラと窓の間」にある。1 個だけ外れた段階ではまだベランダの物なので枠の後ろのまま。
他の 4 種は `overlay` を持たないので従来通りの描画順。

## A. レイアウトの単一情報源（blocking bug）
`pinch.js` が `slot: 0.475 / wFrac: 0.19` を自前で上書きしていたため、竿上でズボンと重なり
縦画面で隠れていた。**`slot` / `wFrac` / `hFrac` は `items/index.js` のみ**が持ち、
どのアイテムクラスも上書きしない（メッシュ列数・クリップ本数・クリップ列は「構造」なので各アイテム可）。
竿全長に対する比率で詰め直し、シャツの袖（`SLEEVE_OVERHANG = 0.24`）も本体幅に算入。

- ヒット判定: `hitPad` は全アイテム **64 css px 以上**（従来 32）。当然パッドは隣と重なるので、
  `main.js onDown` は **`hitDistance * 1000 + 重心距離`** で選ぶ。さらに `hitDistance` を
  「バウンディングボックスまで」→「**メッシュ頂点まで**」に変更した。突風で揺れた布の箱は
  布の 1.5 倍の幅になり隣家まで届くが、メッシュは嘘をつかない。
- `pullThreshold` は `min/390` → **`sqrt(min/390)`** 。iPad は幅が iPhone の 2.1 倍でも
  4 歳児の腕の長さは同じ。個別 `pullPx` の再調整は不要だった（全否定テストが通過）。
- `Item` の interface コメントに `overlay` を追記し、基底コンストラクタで `this.overlay = false`。

## C. 縦画面の風
縦の `inDir` は下向き＝2.5D では「カメラ方向」なので、ゲーム中で最も強い風が画面上で
何も起こさなかった。突風時に同時に 3 つ起こるようにした:
1. **横揺れ**: `weather.js` が `inDir` と直交方向へ実際のキックを加える。突風ごとに向きが反転
   するので、洗濯物は振れて戻る（画面外へ歩いていかない）。
2. **手前への膨らみ**: `setClothScale` を「横 +13% / 縦 −11%」で呼ぶ。カメラへ膨らむ布は
   横に広く縦に短く映る。これが遠近感。既存の 2.5D ヘルパの再利用であり複製ではない。
3. **裾が上がる**: 下の行ほど強い上向き加速（`rv²` 重み）。
横画面は元から `inDir` 方向＝右へ振れるので、突風の倍率を上げるだけ。
**FIRST_DROP 直後の最初の突風は "hero gust"**: 力 1.9 倍、0.75 秒フル保持、
その間すべてのばさみが揺れて光る。

## D. キャラクターの立ち位置
縦: 室内の**右寄り＝サッシ側**（把手は右に格納されている）に立ち、バスケットは左へ移動。
足元線を室内高の 72% → **60%** に上げ、身長を `min*0.24` → `min*0.27`（縦のみ）に。
横: 立ち位置を窓寄り（室内幅の 22% → 14%）へ。`world.charHome` を layout が返し、
「戻る」先も同じ場所になった。
FIRST_DROP で**ガラスを見上げて小さく跳ねる**（`character.startle`）。SPOT で
**最も濡れている一枚**を見て指さし、以後 **4.2 秒ごとに指さしを繰り返す**。
最初に何かを掴んだ瞬間（`main.onDown`）に恒久停止。矢印は一切無し。視線の追従量も強めた。
シーツの「抱える」演出は `sheet.spec.js` で従来どおり通過（`portrait-sheet-hug.png`）。

## E. シーツの陰影
10 段階の量子化を quad ごとに適用していたため、矩形のパッチワークに見えていた。
**32 段階**へ増やし、描画前に各 quad を**上下左右の隣と平均**（自分を 2 倍で重み付け）する
パスを追加。ランプ自体も再調整し、平らな布がパレット中央に来るようにした
（従来は上端に張り付いて、白いシーツは折り目が全部白に潰れていた）。
`drawClothLit` は全アイテムが使うようになり、小物も突風で光と影を持つ。
スクラッチバッファは 2 本を使い回し、毎フレームの確保はゼロ。

縦画面・ばさみ 3 個解放時のシーツは、窓の開口下端（y=490.2）を **約 68 px 超えて**室内側へ
膨らむ（`overlay` 描画）。`zoomTo` を `1+0.085×n` → `1+0.135×n`、縦の `_blow` を 1.45 倍にした。
併せて `_keepInView`（固定されていない点だけを画面内へ押し戻す柔らかい壁）を追加
— 見えない見せ場は見せ場ではない。

## F. 最初の一滴（timeScale 1 実測）
`beats.spec.js` "the first drop" が実時間で検証:
CALM **2.4〜4.5 秒**（実測約 3.0）→ ガラスに**一滴だけ**。その後 **1 秒間**、
雨量 0・突風 0・どの洗濯物にも濡れ跡 0 のまま滴だけが伝う → SPOT は**一枚だけ**に付く →
WIND（この時点で雨量 < 0.2）→ RAIN_RAMP。
滴自体: 竿に被らない位置へ下げ、影を濃く、走りながら少し痩せる。
世界は息を止める（`weather.setStill`: そよ風が 1/5 に落ちる）。キャラクターは見上げて跳ねる。

## G. 空の竿と最後のサッシ
- 把手: 幅 `min*0.030→0.038`、高さ `0.10→0.125`、揺れ幅を **0.16 → 0.55 倍**（+ 微回転）、
  背後に脈動するハロー。**静止 1 フレームで見えること**を
  「把手だけを 0.34 秒あけて 2 回スクリーンショットし、2 枚が異なること（差分 > 2%）」で検証。
- カーテン: 室内側への振れ幅を拡大（常に内向きにオフセット）。
- **窓枠に当たる雨**: 下枠を伝う短い筋と水玉を 9 本（`sash.drawFrameRain`、EMPTY_LINE 以降のみ）。
- 閉めるとき: スライド音は速度連動（既存）、端で「カチッ」、`setIndoor(true)` で
  雨音はローパス 600Hz + ゲイン 0.34 倍、室内は暖色に、キャラクターは安堵（既存経路を確認）。
- AFTER: 3 秒後のみ、画面のどこでもタップで最初から（`audio.spec.js` で 3 秒前は無反応、
  3 秒後は CALM に戻ることを検証）。

## H. 本物のタッチ
`touch.spec.js`（`hasTouch: true, isMobile: true, deviceScaleFactor: 3`、iPhone 390×844）。
CDP の `Input.dispatchTouchEvent` で生のタッチ列を送り、pointer イベントはブラウザに
合成させる（= 実機と同じ経路）。タオルとシーツを実際のジェスチャで取り込み、
さらに**ドラッグの途中で 2 本目の指**を別アイテム（ズボン）の上に置く
→ 1 本目は最後までジェスチャを完遂し、2 本目は何も起こさない。

## I. 音が全く無い状態

参照すると throw するよう定義。`audio.ok === false` を確認した上で、
縦横 2 viewport で 5 種すべて取り込み → サッシ閉 → AFTER まで到達。console エラー 0。
隠し再スタートも動作。

## 非テキストの再確認
`fillText` / `strokeText` を throw に差し替えた状態で全フェーズ・セットピース通過（既存 3 テスト）。
DOM テキストは全テストで空文字。
