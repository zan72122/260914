## 描画順の判断（シーツがサッシ枠より前に出る理由）
`Item.overlay` が真のアイテムは `sash.drawFrame` の **後** に描かれる（`main.js`）。シーツは

## A. レイアウトの単一情報源（blocking bug）
`pinch.js` が `slot: 0.475 / wFrac: 0.19` を自前で上書きしていたため、竿上でズボンと重なり
縦画面で隠れていた。**`slot` / `wFrac` / `hFrac` は `items/index.js` のみ**が持ち、
どのアイテムクラスも上書きしない（メッシュ列数・クリップ本数・クリップ列は「構造」なので各アイテム可）。
竿全長に対する比率で詰め直し、シャツの袖（`SLEEVE_OVERHANG = 0.24`）も本体幅に算入。

- ヒット判定: `hitPad` は全アイテム **64 css px 以上**（従来 32）。当然パッドは隣と重なるので、
  `main.js onDown` は **`hitDistance * 1000 + 重心距離`** で選ぶ。さらに `hitDistance` を
  「バウンディングボックスまで」→「**メッシュ頂点まで**」に変更した。突風で揺れた布の箱は
  布の 1.5 倍の幅になり隣家まで届くが、メッシュは嘘をつかない。
- `pullThreshold` は `min/390` → **`sqrt(min/390)`** 。iPad は幅が iPhone の 2.1 倍でも
  4 歳児の腕の長さは同じ。個別 `pullPx` の再調整は不要だった（全否定テストが通過）。
- `Item` の interface コメントに `overlay` を追記し、基底コンストラクタで `this.overlay = false`。

## C. 縦画面の風
縦の `inDir` は下向き＝2.5D では「カメラ方向」なので、ゲーム中で最も強い風が画面上で
何も起こさなかった。突風時に同時に 3 つ起こるようにした:
1. **横揺れ**: `weather.js` が `inDir` と直交方向へ実際のキックを加える。突風ごとに向きが反転
   するので、洗濯物は振れて戻る（画面外へ歩いていかない）。
2. **手前への膨らみ**: `setClothScale` を「横 +13% / 縦 −11%」で呼ぶ。カメラへ膨らむ布は
   横に広く縦に短く映る。これが遠近感。既存の 2.5D ヘルパの再利用であり複製ではない。
3. **裾が上がる**: 下の行ほど強い上向き加速（`rv²` 重み）。
横画面は元から `inDir` 方向＝右へ振れるので、突風の倍率を上げるだけ。
**FIRST_DROP 直後の最初の突風は "hero gust"**: 力 1.9 倍、0.75 秒フル保持、
その間すべてのばさみが揺れて光る。

## D. キャラクターの立ち位置
縦: 室内の**右寄り＝サッシ側**（把手は右に格納されている）に立ち、バスケットは左へ移動。
足元線を室内高の 72% → **60%** に上げ、身長を `min*0.24` → `min*0.27`（縦のみ）に。
横: 立ち位置を窓寄り（室内幅の 22% → 14%）へ。`world.charHome` を layout が返し、
「戻る」先も同じ場所になった。
FIRST_DROP で**ガラスを見上げて小さく跳ねる**（`character.startle`）。SPOT で
**最も濡れている一枚**を見て指さし、以後 **4.2 秒ごとに指さしを繰り返す**。
最初に何かを掴んだ瞬間（`main.onDown`）に恒久停止。矢印は一切無し。視線の追従量も強めた。

## 設計判断（統制）

仕様 §4 の「別々の操作感」を、Phase 2 では **指の文法の違い**（シャツ＝持ち上げてから弧／
ズボン＝250ms 保持／タオル・シーツ＝1ストローク1ペグ）として実装していた。
これは4歳児には **発見不可能** であり、実際に発見されなかった。

DESIGN.md の原則に立ち返る：「**現実の指使いではなく、プレイヤーの意図を一本指入力へ変換**」。
したがって Phase 4 では次を統制ルールとする。

> **共通の入口ジェスチャは「布のどこでもいいので触って、部屋の方向（`inDir`）へ引く」。
> これは全5種で必ず目に見える進捗を生み、1ストロークで引き続ければ必ず全解放に至る。**

違いは **指に要求するもの** ではなく、**世界が返すもの**（抵抗・順序・布の挙動・音・キャラの動き）
に置く。従来の固有ジェスチャは「見つけた人へのご褒美」として残し、必須ではなくした。

| 5 | シーツ | 手に近いペグ → **0.42s の間に解放された角が風をはらむ** → 次、と順に。最後で BASA＋ぎゅっ | 34 / 0.42 | ペグに触れる |

- 逆方向・横方向へ引いても **絶対に解放しない**（全5種で検証）。
- 指を離したら `settleCloth`（拘束8回＋シア＋速度ゼロ）＋ 0.6 秒の追加緩和で、
  **ギザギザ・棒状・伸びきりのまま固まることが無い**。

## プレイテスト指摘への対応

| # | 指摘 | 対応 |
|---|---|---|
| 1 | 掴んだ手応えが無い（風の揺れと区別できない） | `Item.grabFeedback()`: 触れた瞬間に布が `inDir` へ持ち上がり（裾ほど大きく）、明度が上がり（`grabLit`）、ペグが跳ね（`grabWob`）、「ふさ」と鳴る。ピンチハンガーは剛体なので **枠ごと室内へ寄る**（`lean`） |
| 2 | 誘導が無い | 最初に何かを掴むまで、**3秒ごとに 2秒間**、いちばん濡れている一枚を指さす。腕は太く長く、手と指先を描き、視線も同時に向く。指された一枚の**ペグが光る**（`cueGlint`）。濡れ跡は大きく・濃く・時間とともに広がる |
| 3 | 雨の予告が弱い／遅い | ガラスの一滴を約1.5倍に拡大＋影を強化。SPOT で空が暗くなり始め（`darkFloor` 0.18）、WIND でさらに（0.34）→ **5〜7秒で「降りそう」が読める**。キャラは最初の一滴で跳ねて見上げる（ホップ量 +38%） |
| 4 | 背景・キャラ・かごが無反応 | キャラ＝笑って2回跳ねる／かご＝コンと傾く／竿＝リンと鳴り**全アイテムのペグが揺れる**／濡れた床＝波紋。すべて小さな合成音付き、文字なし、進行には一切影響しない |
| 5 | かごの中身が「後ろに置かれた」ように見える | かごを **内側 → 洗濯物 → 前壁 → 前縁** の順で描画。1枚目は縁が横切る位置に入り、積み上がって縁の上に出る |
| 6 | 当たり判定がシビア | `hitDistance` を **頂点距離からメッシュ内包判定** に変更（布の上なら距離0）。ピンチハンガーの中央を掴んだ指が隣のズボンに取られる事故が消えた。パッドは全種 64px 以上 |
