# v1 監督レビュー（スクリーンショット精査に基づく修正指示）

## A. ライス（最優先）
- 混ぜ後のライスが「皿いっぱいの平らな真紅の液体」に見える（トマトスープ／血のよう）。おいしくない。
- 修正: **皿の内側より一回り小さい、ふくらんだ楕円のマウンド**にする（皿内径の約 72% 幅、縦は 62% 程度）。
  上面ハイライト・下縁の落ち影・側面のグラデで「盛られた山」に見せる。周囲に皿の白が見えること。
- 色は真紅ではなく **チキンライスのオレンジ寄りの赤**（例: #E85A2A〜#D9431E、ハイライト #F58A4A）。米粒テクスチャは残す（粒は薄いオレンジ白）。
- 混ぜる前の白いご飯も同様にマウンド（白〜クリーム、粒テクスチャ、上面ハイライト）。皿いっぱいの平らな円ではなく。
- 混ぜ途中の「白→赤」塗りはこのマウンドの上で行う（マウンド形状にクリップ）。8割で一気に整形して弾む演出は維持。

## B. オムレツとライスの大きさ関係
- 皿の上に乗ったオムレツが小さい。オムレツはライスマウンドの幅の約 85%、縦 70% 程度でマウンドに「乗っている」感（接地影、マウンドの縁が周囲に少し見える）。
- 着地後、ライスとオムレツが一緒にぷるんと揺れる（既存 springWobble を維持、振幅は視認できる程度）。

## C. パカッ→トロッの最終形（最優先）
- 現状の開いた後は「両端の半楕円クリップ＋中央の平面」で、切れて開いたようにも、とろとろにも見えない。
- 目標イメージ: 本物の「パカッとオムライス」写真。
  1. 切れ目から左右の**薄皮が外側へ倒れ**、倒れた皮は少し丸みを帯びて（外側に緩やかなカーブ、下側に影）ライスの両脇に垂れる。
  2. 中央からは**半熟のとろとろ**（明るい黄〜オレンジ #FFD24A→#F7A928、白っぽい艶）が**手前と左右へ流れ広がり**、ライスマウンドの上面を覆い、縁はふっくらとした丸い滴形で止まる。
  3. 表面に大きく滑らかな**スペキュラ**が走り、湯気のような微かな白い揺らぎがあると尚良い。
  4. 最終的に「大きな黄色い面」が描画キャンバスになる（ケチャップで描ける面積が十分に広い）。
- タイムライン: 間 0.3s → パカッ 0.3s（皮が倒れる、少しオーバーシュート）→ トロッ 0.5s（とろとろが ease-out で広がり艶が走る）。
- この演出を **フレームキャプチャ**して確認できるようにする（下記 E）。

## D. レイアウト細部
