## F5 スコープ（docs/01.md 4.6 と 3.4）
- `js/audio.js`: Web Audio で合成。効果音＝持ち上げ（短い木音）、置く（コトン）、はまる（上向き2音）、雨（ノイズ＋ローパス）、光（高音パッド）、開花（アルペジオ）、種が落ちる（小さな音）。環境音＝風（フィルタ付きノイズをLFOで揺らす）、鳥（正弦波グリッサンドをランダム間隔）。環境音は控えめ（効果音より約 -18dB）。初回の pointerdown で `AudioContext.resume()`、`visibilitychange` で停止・再開。音が出なくても遊べること（失敗しても例外を投げない）。
- セーブ: `localStorage` に「解いたパズル番号」だけを保存し、起動時に該当状態（配置・レイヤー・彩度・T3 の有無）を演出なしで復元。エンディング後は保存を消す。リセットは花を3秒長押し（唯一の隠し操作）。
- `manifest.webmanifest`（standalone, display any orientation, 背景色は羊皮紙、アイコンは `art/icon.svg` の種または花。`name`/`short_name` は画面に出ないため許可。`apple-touch-icon` 用に SVG を参照するか、`<link rel="apple-touch-icon">` は PNG が必要なため省略可）。
- 縦画面での上下余白・横画面での左右余白の飾りは維持。
