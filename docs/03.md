# 03. ステージ拡張(18面 → 30面)— 実装プラン

状態: **承認済み・実装済み**

前提: `docs/01.md`・`docs/02.md` の18面は変更しない。

## 0. 決定事項(質問への回答)

| 項目 | 決定 |
|---|---|
| 総レベル数 | 30面(既存18 + 新規12)。星空は1画面のまま |
| 新法則 | 回る円(軌道)、染まる円、ワープ(渦のペア)、流れ(帯) |
| ワープ | じぶんの円も他の円もすべて通れる |
| 回る円 | 触れると軌道から外れ、その瞬間の進行方向(接線)へ飛び出す。外れた後は押せる |
| 流れ | まっすぐな帯。じぶんの円も流される(指を動かせば逆らえる) |
| 染まる円 | 白い円(押せる)が、色付きの「絵の具」円にぶつかるとその色になる。輪と同じ色のときだけ入れる。塗り直し可 |
| ごほうび | 現状維持(追加なし) |
| 既存面 | 触らない |

## 1. 新しい円の法則

すべて「触れた瞬間の反応」と「動きの見た目」で分からせる。文字・矢印・アイコンは使わない。

| 法則 | 色 | 見た目のシグニファイア | 振る舞い |
|---|---|---|---|
| **回る円** `orbit` | 空色 `#4FC3F7`、中心は小さな濃紺の点 | 中心の周りに薄い円の軌道線。円はその上を一定速度で回り続ける | じぶんの円が触れると軌道から外れ、その瞬間の接線方向へ飛び出す(`push` と同じ物理に切り替わる)。輪の色は空色。外れた円は押して調整できる |
| **染まる円** `dye` + **絵の具** `paint` | 白 `#FFFFFF`(縁は薄灰)/ 絵の具は任意の色 | 白い円は「まだ色がない」ので輪(色付き)に合わない予感。絵の具の円は静止して、表面が波打つ | 白い円は押せる。絵の具にぶつかると、ぽん、とその色に染まる(波紋アニメ)。別の絵の具にぶつければ塗り直せる。輪は `target: { type: 'dye', color }` で色一致を要求 |
| **ワープ** `warp` | 藍 `#3F51B5` の渦(回転する二重らせん) | 対になった2つの渦が同じ向きに回転。近づくと吸い込む | 円(じぶんの円を含む全て)が渦の中心付近に入ると、対の渦から同じ速度で出てくる。出た直後は再突入しない(短い無効時間)。じぶんの円は指の位置に戻ろうとするので、ワープ後は「指を離した位置」から追従を再開する(指を置き直すまで待つ) |
| **流れ** `flow` | 帯は背景より少し濃い色、粒は白 | 画面を横切るまっすぐな帯。帯の向きに流れる小さな粒が常に見える | 帯の中にある円は帯の向きに一定の力で流される。じぶんの円は帯の中では指への追従が弱まり、流れに引きずられて指から遅れる。指を動かせば逆らえる。指を離すと流される |

輪の拡張: `target` に `color` を追加できる(染まる円用)。輪の色は `color` があればそれを使う。

## 2. レベル設計(19〜30面)

紹介→応用の2面ペアを4組(19〜26)と、総合4面(27〜30)。

| # | 法則 | 配置(概要) | 気づき方 |
|---|---|---|---|
| 19 | **流れ**(紹介) | 画面中央を横切る帯(右向き)。じぶんの円は帯の下。輪は帯の右端の先 | 帯に入ると流される → 流れに乗って輪へ |
| 20 | 流れ + 押す | 押せる緑の円が帯の上流側にある。輪は下流側の帯の中 | 押して帯に入れると勝手に流れて輪へ |
| 21 | **ワープ**(紹介) | 壁(gate、隙間なし = 通れない壁)が画面を分ける。手前に渦、向こうに対の渦と輪 | 壁を越えられない → 渦に入ると向こうへ |
| 22 | ワープ + ついてくる | 黄の円がついてくる。渦は黄も通る。輪は壁の向こう | 自分が渦に入ると黄もついて来て渦を通る |
| 23 | **回る円**(紹介) | 中心の点の周りを空色の円が回る。輪は軌道の外側、右上 | 触れると飛び出す → 飛んだ方向が輪でなければ押して調整 |
| 24 | 回る円 ×2 + 輪 ×2 | 2つの軌道(内・外)。輪は2つ | 2回タイミングを合わせる |
| 25 | **染まる円**(紹介) | 白い円1つ、絵の具(赤)1つ、赤い輪 | 白いままでは輪が光らない → 絵の具にぶつけると赤に → 入る |
| 26 | 染まる円 ×2 + 絵の具 ×2 + 輪 ×2 | 白2つ、絵の具(赤・青)、輪(赤・青) | 色を合わせて2つ |
| 27 | 流れ + 壁 + 縮む | 帯が壁の隙間を通り抜けている。縮んで帯に乗ると隙間を通れる | 2面の応用 + 縮む |
| 28 | ワープ + 押す + 輪 | 押せる円を渦に送り込むと壁の向こうの輪の近くに出る | 円を渦に送る |
| 29 | 回る円 + 流れ | 飛び出した空色の円が帯に落ちると輪まで流される | タイミング + 流れ |
| 30 | フィナーレ: 染まる + ワープ + 流れ + 輪 ×2 | 白い円を赤に染め、渦で壁の向こうへ送り、帯で赤い輪へ流す。じぶんの円も渦と帯を通って帯の先の輪へ | 総まとめ。クリア後は全色の祝福(実装時に白2つ→1つに簡素化) |

30面は法則3つ + 輪2つ(上限内)。

## 3. 星空マップ

- 30面を1画面に。縦: 5列 × 6行、横: 10列 × 3行(蛇行)。星の半径は列数に合わせて自動で小さくなる(縦は現在の約 70%)。
- 全30面クリアで祝福演出 → 星空へ。それ以外は現状通り。

## 4. 実装ステップ

1. **法則**: `js/laws.js` に orbit / dye / paint / warp / flow を追加。輪の `target.color` 対応。
2. **描画**: 軌道線、渦の回転、帯の流れる粒、絵の具の波打ち、染まる波紋。
3. **音**: 飛び出す(ひゅっ)、染まる(ぽん、色ごとに音程)、ワープ(すうっ→ぽん)、流れ(乗っている間の小さなさらさら音)。
4. **19〜30面**の定義と数値調整。
5. **星空**: 列数を面数から決める。
6. **検証**: Playwright 自動プレイに新法則の戦略(帯に乗せる、渦に送る、タイミング待ち、絵の具へ押す)を追加し、縦/横/iPad で30面すべてクリアできることと、星空・各面の見た目を確認。

## 5. 行き詰まり防止

- 回る円は外れた後は押せる円と同じ物理になるので、既存の端からの押し戻し・速度上限が効く。
- ワープ後は「渦から出るまで」再突入しない(時間ではなく位置で判定)。渦の対はどちらからも入れる。
- じぶんの円が渦を通った直後は、指を置き直すまでその場で脈動して待つ(指のずれ方式は届かない場所ができるため不採用)。
- 流れの帯の下流端は画面内で終わり、その先で円は止まる(画面外へ流れない)。
- 染まる円は何度でも塗り直せる。
- 輪は、ぴったり合う円が近くを通ると引き寄せる(流れで少し外れても入る)。
- じぶんの円の輪は最後に入る(他の輪が残っている間は入らない。入ると動けなくなるため)。
- 押せる円同士は重ならない。端に寄った円は、じぶんの円が裏側に回れる幅まで内側へ戻る。
- ついてくる円は、相手が壁で見えないとき、まっすぐ行ける渦へ向かう。
