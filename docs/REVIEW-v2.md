# v2 監督レビュー（フレームシート精査に基づく修正指示）

v2 で A（ライスの山）・B（大きさ）・D（レイアウト）は合格。残るはシグネチャー2点の動きの質。

## 1. パカッ→トロッ（open フレーム 9→10 の問題）
- frame 9 は閉じたオムレツ、frame 10 で**いきなり全開**になっている。パカッの 0.3s の途中経過が見えない（皮が倒れていく動きが無い）。フレームキャプチャの step が正しく効いているか含めて確認し、**皮が回転して外へ倒れる過程が 4〜5 フレーム（60ms 刻み）で見える**ようにする。
- frame 10〜14 の間、両皮の間に**赤いライスの塊が大きく露出**し、その上にきらめきが乗っている。これは「開いたら赤い肉塊」に見えて美味しくない。
  - 皮が開き始めた時点（開き 40% 程度）から**とろとろが切れ目から溢れ始める**ように重ねる（タイムラインの重複）。
  - とろとろは「中央で楕円が膨らむ」のではなく、**切れ目の線から液体が左右・手前へ流れ広がる**動き（横に広く、手前に垂れ、先端は丸い滴、ease-out）。
  - きらめきはライスの上に出さない。とろとろが広がりきった後に黄色面の上で小さく数個だけ。
- 両側の皮が「黄色い丸い玉」に見える。**薄い卵のシートが外側へめくれてとろとろの両脇に寄り添う三日月形**に。内側（切り口側）は少し暗い焼き面、外側は艶。厚みは薄く。
- 最終形（frame 25）は概ね良い。上記を反映しても「大きな黄色い描画面」は維持すること。

## 2. オムレツのスライド（slide フレーム 1〜6 の問題）
- frame 1〜4 でフライパンが**全く傾いて見えない**。ドラッグ進捗に応じて明確に傾けること: 皿方向へ約 12° 回転＋皿方向へ最大 18% 移動＋縦スケール 0.85 程度、皿側の縁が下がって見える影の変化。
- 卵は傾きに合わせて**縁へ向かってじわっと寄り**、進捗 1 で縁を越えて**伸びながら（縦長にストレッチ）**滑り出す。
- frame 5 では卵が空中の高い弧を飛んでいる。「スルッ」ではなく「投げた」ように見える。軌道は**フライパンの縁から皿のライス上面へ低い滑り台状**（高さは控えめ、距離は短く）にし、着地で潰れて（横に広がって）から戻る squash & stretch。
- 着地後にライスも一緒に揺れる（frame 6〜10）は良い。維持。

## 3. レビュー用ツール
- `tests/sheet.js` を追加した（Playwright の Chromium でフレームのコンタクトシートを作る）。`npm run frames` の後に `npm run sheet` で `screenshots/frames/sheet-open.png` と `sheet-slide.png` が出るように package.json に組み込む（引数: prefix, out, crop "x,y,w,h"。open は `0,60,390,280`、slide は `0,60,390,600`）。NODE_PATH は不要なように tests/ から相対 require にする。
