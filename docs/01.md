# 01. Circles風 Wordless パズルゲーム — 実装プラン

状態: **承認済み・実装済み**

## 0. 決定事項(質問への回答)

| 項目 | 決定 |
|---|---|
| 技術構成 | 素の HTML + Canvas 2D + Vanilla JS。ビルド・依存なし |
| サウンド | Web Audio API による合成音のみ(音声ファイルなし) |
| 規模 | 約6レベルのプロトタイプ |
| 進行 | 失敗なし。クリアで自動的に次へ。進捗は localStorage |
| 操作 | 指でなぞる(ドラッグ)のみ。タップ・ボタン・ジェスチャーなし |
| 見た目 | 明るく彩度高め(白/パステル背景 + はっきりした色の円) |
| 公開 | ローカルで開くだけ(公開設定はしない) |
| ブランチ | `claude/circles-wordless-game` |

## 1. コンセプト

- 画面には **円しか存在しない**。文字・アイコン・ボタン・メニュー・数字はゼロ。
- 指を置いた場所に「じぶんの円」が現れ、指についてくる。
- 各レベルには **空っぽの輪(ゴール)** がある。輪は中身がない=「何か入るはず」という知覚的不完全さがそのまま目標になる。
- 輪にぴったり合う円が入ると、輪が満たされて広がり、画面全体が次の面の背景色に変わる(世界そのものが場面転換する)。
- 各レベルは「円の法則」を1つずつ紹介する。法則は説明せず、触った瞬間の反応(大きくなる/逃げる/ついてくる/押される)で分からせる。

## 2. Wordless interaction の具体策

| 原則 | 実装 |
|---|---|
| 知覚されたアフォーダンス | じぶんの円は指の下に生まれ、指の動きに即追従する(遅延ゼロ)。「指=円」を初回タッチで体感 |
| 顕著なシグニファイア | ゴールの輪は太い縁取りでゆっくり呼吸(拡縮)し、中身が空。正解サイズの円が近づくと縁が明るく光り、引き寄せられる |
| 物理的因果 | 押せる円は指の円が当たると滑らかに動き、摩擦で止まる。逃げる円は指から離れる方向へ、ついてくる円は指の方へ |
| 自然な写像 | 指の位置=円の位置。近づく=影響が強くなる(拡大・縮小の量が距離に比例) |
| 知覚的不完全さ | ゴールの輪が空/じぶんの円が輪より小さい・大きい → 「合わせたい」が自然に生まれる |
| 即時フィードバック | 触れる・膨らむ・縮む・押す・入る、すべてに色の変化+短い合成音 |
| 無操作時の誘い | 数秒触れないと、じぶんの円が小さく脈動。レベル1のみ、半透明の円が指の円から輪へ一度だけ流れて消える(デモ) |
| 失敗なし | ゲームオーバー・タイマー・スコアなし。行き詰まりは起きない設計(法則が可逆) |
| 場面転換 | クリア時に輪が膨らんで画面を塗りつぶし、それが次の面の背景になる。ボタンや「次へ」表示は不要 |

## 3. レベル設計(6面)

じぶんの円(以下P)の基本半径を R とする。ゴールの輪は「合う半径」を持ち、輪の縁の太さ・色でどの円が入るべきかを示す(輪の色 = 入るべき円の色)。

| # | 紹介する法則 | 配置 | 気づき方 |
|---|---|---|---|
| 1 | **動かす** | P と同サイズの輪が画面中央上部。P は下部に初期配置 | 指を置くと円が現れ、動かすと輪に入る。デモの流れ円あり |
| 2 | **膨らむ** | 輪は P より大きい。近づくと P を膨らませる「あたたかい円(オレンジ)」が途中にある | 輪に入れない → 途中の円に近づくと P がむくむく膨らむ → 入る |
| 3 | **縮む** | 輪は P より小さい。近づくと P を縮める「つめたい円(水色)」がある | 2の逆。距離に応じて連続的に変化 |
| 4 | **押す** | 輪の色は P ではなく別の「ころがる円(緑)」の色。P は輪より小さく入らない | P で緑の円をつつくと転がる → 輪へ押し込む |
| 5 | **逃げる** | 「はずかしがりの円(ピンク)」が P から逃げる。輪は画面の角にある | 追うと逃げる → 逃げる方向に輪がある → 角へ追い込むと入る |
| 6 | **ついてくる** | 「なかよしの円(黄)」が P についてくる。輪は P が通れない「縮める円」の帯の奥にある | P が先導すると付いてくる → P は縮んで通れるが黄は縮まない… ではなく、黄が輪に入ればクリア。P は輪に入れない(色が違う)ことで役割が分かる |

6面クリア後は祝福演出(全ての色の円が画面に弾ける)ののち、1面へ戻る(ループ)。

## 4. 画面・入力仕様(iPhone/iPad)

- `<meta viewport>` で拡大禁止、`touch-action: none`、`overscroll-behavior: none`、`-webkit-user-select: none`。
- `apple-mobile-web-app-capable` を指定し、ホーム画面に追加すれば全画面。
- Canvas は `devicePixelRatio` 対応。縦横どちらも対応: レベル座標は **正規化座標**(x, y は 0..1 の画面比率、半径は短辺比)で定義し、回転時は再レイアウト。
- セーフエリア(`env(safe-area-inset-*)`)を避けて配置。
- 入力は Pointer Events(1本目の指のみ)。マウスでも同じ挙動(開発確認用)。
- 指を離すと P はその場に残る(次に触れた場所へ滑らかに移動)。

## 5. サウンド(Web Audio 合成)

- 初回タッチで AudioContext を resume(iOS の自動再生制限対応)。
- 効果音: 触れる(短いポン)、膨らむ/縮む(距離に応じたピッチのうなり)、押す(こつん)、輪に入る(上昇アルペジオ)、面転換(やわらかいスウェル)。
- 音量は控えめ、全て正弦波+短いエンベロープで耳に優しく。BGM なし。

## 7. 実装ステップ

1. 骨組み: index.html + Canvas 全画面 + DPR + 回転対応 + Pointer 入力。
2. P の描画と追従、ゴールの輪の描画(呼吸・光り・吸い込み・クリア判定)。
3. 場面転換演出(輪が広がって背景色になる)と localStorage 進捗。
4. 法則の実装: grow / shrink / push / flee / follow。
5. 6面の配置とパラメータ調整。
6. 合成音の追加。
7. 無操作ヒント(脈動・レベル1のデモ)。
8. 動作確認: Playwright(ヘッドレス Chromium)で縦(390×844)/横(844×390)/iPad(820×1180)のスクリーンショットを撮り、全面がクリア可能かをスクリプトで自動プレイして確認。
