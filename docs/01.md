## 0. 決定事項(質問への回答)

| 項目 | 決定 |
|---|---|
| 技術 | Three.js + Vite(iPhone/iPad Safari で動作) |

## 1. コンセプト

箱型モンスター「ハナ」の頭の中はお花畑。
ハナは蝶が大好きだが、お花畑は枯れていて蝶が来ない。
プレイヤーは頭の中の仕掛けをさわって、お花畑を目覚めさせ、蝶を呼び、ハナを喜ばせる。

ゴールは文字で示さない。**ハナの視線・表情・頭の中に置かれた物**がゴールを語る。

## 2. Wordless interaction の設計原則(本作での具体化)

| 原則 | 本作での実装 |
|---|---|
| 知覚されたアフォーダンス | 引けるものは紐が垂れている。押せるものは出っ張った丸ボタン。回せるものは取っ手つき。 |
| 顕著なシグニファイア | 「次にさわるべき物」だけが呼吸するように脈動し、小さな光の粒を出す。他は静止。 |
| 身近な物理的因果 | じょうろを傾ける→水が出る→土が濡れる→芽が出る。太陽を出す→明るくなる→花が咲く。 |
| 自然な対応づけ | 指の動きと物の動きが一致(右にひねれば右に回る、上に引けば上に伸びる)。 |
| 知覚的な不完全さ | 空っぽの植木鉢、閉じた蕾、垂れ下がった雲、寂しそうな顔。「足りない」ことが目に見える。 |
| 即時の視覚フィードバック | 触れた瞬間に必ず何かが動き、音が鳴る(効果がなくても、ぷるんと揺れる)。 |

追加ルール:

- 画面上に**文字を一切出さない**(タイトル・ボタン・ヒント・クリア表示すべて)。
- タイマー・スコア・失敗・ゲームオーバーは存在しない。何をしても壊れない。
- どこを触っても何かが反応する(無反応は「壊れた」と感じさせるため禁止)。
- 手詰まり検知: 15秒操作がなければ、次に触るべき物が少し大きく脈動し、ハナがそちらを見る。
- 音は「正解の音」ではなく「その物の音」。じょうろは水音、ボタンはポン、紐はシャラン。

## 3. 世界の構造

### 3.1 外側: ハナ(箱)

- 角丸の立方体。正面に大きな目2つと口。頭の上に小さな蕾のような飾り。
- 起動直後: 箱が閉じた状態で画面中央に浮いて、ゆっくり上下に揺れている。
- 目はプレイヤーの指(タッチ位置)を追う。触られると嬉しそうに目を細める。
- **開け方**: 箱の上面のふたに大きな取っ手。取っ手が脈動している。上にスワイプ(引く)とふたがパカッと開き、カメラが少し寄って中が見える。ふたは開いたまま。
- 初回、何も触らずにいたら 5 秒後にふたがカタカタ動いて「開けて」と誘う。

### 3.2 内側: お花畑(3つの面)

箱の内側は3面のジオラマ。左右スワイプで箱を回し、面を切り替える。

```
      [B: 空と太陽の面]
[A: 花壇の面]        [C: 蝶の木の面]
```

指を離すと最も近い面にスナップ。裏面(D)は無く、A↔B↔C を往復する(端で軽く跳ね返る)。
上下の回転はない。

### 3.3 パズルの流れ(順序は緩やか。手掛かりは世界が語る)

1. **面A: 花壇** — 干からびた土の植木鉢が3つ。横にじょうろ(取っ手あり)。
   - じょうろをタップ&ドラッグして鉢の上へ持っていくと傾いて水が出る。
   - 水がかかった鉢から芽が出る(即時)。3鉢すべてで芽。
2. **面B: 空** — 太陽が雲に隠れている。雲には紐が垂れている。
   - 紐を下に引くと雲がスライドして太陽が出る。世界全体が暖色に明るくなる。
   - 太陽が出ると面Aの芽が蕾になり、色づく(面を戻すと見える。音楽も一段賑やかに)。
3. **面A: 花壇(再)** — 蕾を1つずつタップすると、ぽん、と咲く(3色)。
   - 3つ咲くと花の香り(光の粒)が上に立ち上り、面Cの方向へ流れる(誘導)。
4. **面C: 蝶の木** — 木にぶら下がる蛹(さなぎ)が3つ。粒がぶつかると蛹が揺れる。
   - 蛹をタップするとぐらぐら→もう一度で割れて蝶が出る。蝶は花の色と対応。
   - 蝶が花壇へ飛んでいく。
5. **完成** — 3匹の蝶が花の上で舞う。ハナの目が輝き、頭の上の飾りが花になって咲く。
   音楽が全レイヤー再生。紙吹雪のような花びらが舞う。文字は出ない。
6. **おもちゃ箱モード** — その後も全て触れる。花をタップすると蝶が寄ってくる、
   じょうろで水をやると花が揺れて喜ぶ、雲の紐を引けば夕焼け→夜(星)→朝に切り替わる、など。

順序の強制は最小限(太陽なしでも蕾はタップで揺れるが咲かない=「まだ何か足りない」の知覚)。

### 3.4 縦画面/横画面

- 縦: 箱を画面幅いっぱいに。ハナの顔が下、開いた中身が上に見える構図。
- 横: 箱を中央に少し小さく、余白は空の色。
- 向きの変更はアニメーション付きでカメラ距離を再計算。UI要素はないのでレイアウト崩れの心配は最小。
- `100dvh` と `viewport-fit=cover` で Safari のアドレスバー領域に対応。ピンチズームとダブルタップズームは無効化。

## 4. サウンド設計(Web Audio シンセ)

- **音楽レイヤー**(進行に応じて重なる):
  1. 基礎: 柔らかいパッドのドローン(常時)
  2. 芽が出る: 木琴風のアルペジオ
  3. 太陽が出る: 明るいコード進行のベース
  4. 花が咲く: 鈴のようなメロディ
  5. 蝶: 高音のトリル
- **効果音**: タップ(ポン)、水(ノイズ+ローパス)、紐(シャラン)、開閉(コトン)、蝶(パタパタ)。
- iOS の制約: 最初のタッチで `AudioContext` を `resume()`。それまでは無音でも成立する。
- 音量調整UIは作らない(端末の音量で対応)。

## 5. 技術設計

### 5.1 ディレクトリ

```
index.html
package.json
vite.config.js
src/
  main.js            起動、リサイズ、ループ
  world/
    monster.js       箱・顔・ふた・目の追従
    garden.js        面A: 鉢・じょうろ・花
    sky.js           面B: 雲・太陽・紐・昼夜
    tree.js          面C: 木・蛹・蝶
    particles.js     光の粒・花びら
  interact/
    input.js         Pointer Events 統合(タップ/ドラッグ/スワイプ判定)
    picker.js        Raycaster による対象選択
    hint.js          手詰まり検知と脈動
  audio/
    synth.js         楽器・効果音
    music.js         レイヤー管理
  state.js           進行状態(純粋なオブジェクト、イベント発火)
docs/
  01.md              この計画
```

### 5.2 依存

- `three`(最新安定版)、`vite`。それ以外は入れない。
- モデルは全てコード生成のプリミティブ(Box/Sphere/Cylinder/Lathe)。外部アセットなし。
- トゥーン風の見た目: `MeshToonMaterial` + 軽い輪郭線、パステル配色。

### 5.3 入力

- Pointer Events で統一(タッチ・マウス両対応、開発はPCで可能)。
- 判定: 移動量 < 10px でタップ、オブジェクト上で開始した移動はドラッグ(じょうろ、紐)、何もない場所での横移動は箱の回転。
- ドラッグ中の物は指に追従し、離すと元の位置へ戻る(またはスナップ)。

### 5.4 状態遷移

```
closed → opened → sprouted(3) → sunny → bloomed(3) → butterflies(3) → complete(toybox)
```

各遷移で音楽レイヤーとヒント対象を更新。`localStorage` 保存はしない(毎回最初から。所要 3〜5 分想定)。
