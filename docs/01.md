# 01. プラン: 「つきとしお」— Sizeable風 サイズ変化ジオラマパズル(プロトタイプ)

作成日: 2026-09-13
ブランチ: `claude/sizeable-moon-tide-diorama`

## 1. ゴール

小さなローポリのジオラマ(島・海・月)の中で、オブジェクトを伸縮させて環境を変え、
隠された **柱** を見つけるゲームのプロトタイプを1ステージ分つくる。

対象プレイヤーは4歳女児。**文字を一切使わず**、見れば分かる世界そのものをUIにする。
思い出させない。説明しない。世界が次の一手を誘う。

## 2. 決定事項(質問への回答)

| 項目 | 決定 |
|---|---|
| 技術 | Three.js + Vite(TypeScript)。iPhone/iPad Safari 縦横両対応 |
| 規模 | 1ステージ(プロトタイプ)。ステージ追加は次フェーズ |
| 操作 | タップで掴む → 指を上下にドラッグで伸縮。片手・片指で完結 |
| 配信 | ビルド成果物(`dist/`)をリポジトリにコミット。任意の静的ホスティングに置ける |
| テーマ | 島と月と潮。月を小さくすると潮が引き、海底の柱が現れる |
| 音 | Web Audio で合成した効果音+環境音。外部音源ファイルなし |
| クリア後 | 柱タップ → 祝福 → 同じジオラマで自由に遊び続けられる。柱の再タップで初期状態に戻る |

## 3. ゲーム内容(1ステージ: 島と月と潮)

### 3.1 ジオラマの構成

回転する小さな円盤の上に載った、手のひらサイズの島。ローポリ・パステル調・やわらかい影。

| オブジェクト | 伸縮できる? | 伸縮すると起きること(因果) |
|---|---|---|
| **月**(空に浮かぶ) | ○ | 小さく → 潮が引き、海面が下がる。大きく → 潮が満ち、海面が上がって砂浜まで水が来る |
| **木**(島の上) | ○ | 大きく → 木陰が広がり、木の上のヤシの実が落ちてコロコロ転がる(お楽しみ要素)。小さく → 鳥が飛び立つ |
| **家**(島の上) | ○ | 大きく → 煙突の煙が増え、屋根が伸びる。小さく → ドアからネコが出てくる(お楽しみ要素) |
| **海** | × | 月の大きさに追従して水位が変わる |
| **柱** | ×(タップのみ) | 海底に沈んでいる。潮が十分に引くと露出し、キラキラ光る。タップで祝福 |
| **島・円盤** | × | 円盤は指で左右にドラッグすると回る(見回せる) |

木と家は「正解ではないが触ると何かが起きる」オブジェクト。
触れるものすべてが反応することで、**月も触れる**という発見が自然に起きる。

### 3.2 解法

1. 何かに触る(どれでもよい)→ 伸縮できると分かる
2. 月に触って小さくする → 海が引いていく(即時、連続的)
3. 海底から柱の先端が見え、キラキラ光る(知覚的不完全性: 「もっと引かせたい」)
4. 月をさらに小さくする → 柱が全部出る
5. 柱をタップ → 祝福(紙吹雪・音・柱の光が空へ伸びる)
6. その後も自由に伸縮して遊べる。柱をもう一度タップすると初期状態へ戻る

## 4. Wordless interaction 設計(厳守事項)

文字・数字・矢印アイコン・チュートリアル画面・ボタンUIは**一切置かない**。
以下の仕組みで次の行動を誘う。

### 4.1 知覚されたアフォーダンス(触れるものは触れそうに見える)

- 伸縮可能オブジェクトは常時ごくわずかに **呼吸(0.98〜1.02倍で脈動)** している。動かないものとの差で「これは生きている・触れる」と分かる。
- 指を近づける前(ホバー不可のため)から目立つよう、彩度をわずかに高く、輪郭にやわらかいリムライトを入れる。

### 4.2 顕著なシグニファイア(掴んだら分かる)

- タップした瞬間、そのオブジェクトが **ぽよん** と一度弾み、まわりに光の輪が出る。指の位置に **上向き・下向きの小さな光の粒**が縦に並んで漂う(文字なし、縦に動かす方向を示す)。
- 掴んでいる間、オブジェクトの周囲に薄い縦ゲージのような光の帯(目盛りなし)が出て、指を上げると帯が伸び、下げると縮む。

### 4.3 馴染みのある物理因果

- 月が小さい → 潮が引く(遠ざかった感じ)。月が大きい → 潮が満ちる。
- 大きい木からはヤシの実が落ちて転がる。家が小さいとネコが出る。
- 「見て分かる」因果のみ。抽象的なスイッチやロジックは使わない。

### 4.4 自然な対応付け

- 指を **上** に動かす = **大きく**。指を **下** = **小さく**。世界の上下と一致させる。
- 円盤の回転は指の左右移動と同じ方向。

### 4.5 知覚的不完全性(続きが見たくなる)

- 潮が中途半端に引いた状態で、柱の **先端だけ** が海面から見え隠れし、キラキラする。
- 柱が完全に出ると、キラキラは柱全体を包む光になる → 「これをタップ」と誘う。

### 4.6 即時の視覚・聴覚フィードバック

- 伸縮は指の動きにフレーム単位で追従(遅延なし)。
- 伸縮中は音程が大きさに連動(大きい=低い音、小さい=高い音)。
- 海面の上下は波紋・泡・砂の湿りの色変化で見せる。
- 柱タップ → 紙吹雪・柱から空へ光の柱・チャイム音・ジオラマ全体が一度きらめく。

### 4.7 失敗・迷いの排除

- 「失敗」状態は存在しない。何をしても世界が反応する。
- 何もしないまま約8秒経つと、月が **ひとりでにやわらかく明滅** する(誘導。文字なし)。
- タップ対象外(海や空)をタップしても、そこに小さな波紋が出て「反応はある」と伝える。

## 5. 画面・入力

- 縦画面: ジオラマは画面中央やや下、月は上部。横画面: ジオラマ中央、月は右上。カメラはアスペクト比で自動調整。
- 入力は Pointer Events(タッチ・マウス両対応)。
  - 伸縮オブジェクト上で pointerdown → 掴む。move の縦移動量でスケール(0.4〜2.0倍)。up で離す。
  - 何もない場所で pointerdown → 横ドラッグで円盤回転。
- iOS対策: ダブルタップズーム・長押し選択・ピンチズーム・バウンススクロールをすべて無効化。フルスクリーン風の `viewport-fit=cover`。
- 音は初回タッチで AudioContext を resume(iOS制約)。無音でも遊べることを保証。

## 6. 技術構成

```
/
├── index.html
├── package.json            # vite, three, typescript
├── vite.config.ts          # base: './' (相対パス配信)
├── src/
│   ├── main.ts             # 起動、ループ
│   ├── scene/
│   │   ├── Diorama.ts      # 円盤・島・海・空
│   │   ├── objects/        # Moon, Tree, House, Pillar, Sea, Cat, Coconut, Bird
│   │   └── Effects.ts      # 紙吹雪、光の輪、キラキラ
│   ├── input/
│   │   └── Gesture.ts      # Pointer Events → 掴む/伸縮/回転
│   ├── rules/
│   │   └── TideRule.ts     # 月のスケール → 海面高さ、柱露出判定
│   ├── audio/
│   │   └── Synth.ts        # Web Audio 合成(伸縮音、波、チャイム)
│   └── util/
├── docs/
│   └── 01.md               # 本プラン
└── dist/                   # ビルド成果物(コミットする)
```

- ジオメトリはすべてコード生成(BoxGeometry/CylinderGeometry/ConeGeometry/IcosahedronGeometry の組み合わせ)。外部モデル・テクスチャ・音源ファイルは使わない。
- 描画は `MeshToonMaterial` または平坦シェーディングの `MeshStandardMaterial` でローポリ感を出す。影は1灯のみでモバイル性能を確保。
- 対象: iOS Safari 16+。60fps を目標、描画解像度は devicePixelRatio 上限2。
