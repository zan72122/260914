# 01. 企画・実装プラン：『おりがみの みち』（Paper Trail 風・4歳向け折り紙パズル）

- ブランチ: `claude/origami-road-to-grandma`
- 状態: **承認待ち（この文書が承認されるまで実装しない）**
- 対象: iPhone / iPad の Safari（縦・横どちらでも）。ホーム画面追加でフルスクリーン動作。

---

## 0. 決定事項（ヒアリング結果）

| 項目 | 決定 |
|---|---|
| 技術 | 素の HTML + Canvas 2D + ES Modules。ビルド不要。GitHub Pages で公開 |
| テーマ | 女の子が家を出発し、森・川・山を越えて **おばあちゃんの家** へ |
| 規模 | 上下左右の端を折る「1本の折り目」のみ。全 **10面** |
| 移動 | 行きたい場所を **タップ → 自動で歩く** |
| 折る操作 | 紙の端を **つまんでドラッグ**。半分を越えたらパタンと確定、途中で離すと戻る |
| 音 | 効果音のみ。Web Audio で合成（音声ファイルなし） |
| ヒント | 一定時間無操作で、折るべき端が **風でめくれて揺れる**（アイコン・矢印は出さない） |

## 1. Wordless 設計原則（このゲームでの具体化）

ゲーム内に **文字・数字・アイコン・矢印・ボタン** を一切置かない。次にやることは世界の見た目が招く。

| 原則 | このゲームでの実装 |
|---|---|
| 知覚されるアフォーダンス | 紙の端は常に少し浮いてめくれ、影が落ちている → 「つまめる」と分かる |
| 顕著なシグニファイア | 道は端でぷつんと途切れ、川や崖で断絶している → 「向こうに続きがある」と分かる |
| 物理的因果 | 折ると本物の紙と同じ動き（山折り・裏面が見える・影・紙擦れ音）。主人公の上には折れない（当たって跳ね返る） |
| 自然なマッピング | 折る方向＝指を動かした方向。次の面へ＝**ページをめくる** |
| 知覚的不完全さ | ゴール（おばあちゃん）は毎面 **最初から見えている** が、道がつながっていない。埋めたくなる |
| 即時の視覚フィードバック | 道がつながった瞬間に道が明るくなり、主人公が歩き出せる姿勢（前を向く）になる |
| 記憶に頼らない | 現在の折り状態は紙そのものが示す。操作説明画面・チュートリアル文なし。1面目自体がチュートリアル |

**禁止事項**: タイトル文字、ステージ番号、スター評価、メニュー、設定画面、ポップアップ、確認ダイアログ。

## 2. 遊びの流れ（ユーザー体験）

1. **起動** ＝ 1面目そのもの。机の上に置かれた1枚の紙。家の前に女の子（ハナ）と、手を振るお母さん。画面のどこかにおばあちゃんの家が見えている。
2. 道をタップ → ハナが歩く。道の切れ目で止まり、向こう側を見る（体を傾ける・帽子を押さえる）。
3. 紙の端をつまんでドラッグ → 紙が持ち上がり裏面が見えてくる → 半分を越えるとパタンと折れて確定。裏面の道が表の道につながる。
4. おばあちゃんをタップ → ハナが歩いて到着 → 抱きつく（喜びの効果音） → 紙が **本のページのようにめくれて** 次の面。
5. 10面目のゴールで終幕：おばあちゃんとお茶を飲む一枚絵。しばらく置くとページが最初に戻る（ループ）。

**失敗は存在しない**。間違った端を折っても危険はなく、裏面に「森の壁」「湖」など通れないものが見えるだけ。折り戻せば元通り。

## 3. コアメカニクス仕様

### 3.1 紙（ページ）
- 1面 = 縦横 **4×4 タイル** のほぼ正方形の紙（縦画面・横画面どちらでも同じ見え方で収まる）。
- 各辺に **折り目は1本**（端から1タイルの位置）。折ると幅1タイルの「フラップ」が隣のタイル列の上にかぶさる。
- 紙には **表面** と **裏面** のタイルデータがあり、折ると裏面が左右（または上下）反転してかぶさる。
- 同時に折れるフラップは **最大1枚**（v1）。後半の面は「折る → 歩く → 折り戻す → 別の端を折る」の **順序** で難度を上げる。
- ハナが立っているタイルの上には折れない（フラップが当たって跳ね返る＋「ボヨン」音＋ハナがしゃがむ）。ハナが乗っているフラップは戻せない。

### 3.2 道と歩行
- タイルは道の接続ビット（上右下左）を持つ。折り状態から「今見えている合成グリッド」を作り、接続グラフを更新。
- タップ位置のタイルへ BFS で経路探索。到達不能なら **最も近づける道の端** まで歩いて止まり、目的地の方を見る。
- ゴールタイル（おばあちゃん）に到着でクリア。

### 3.3 折り操作（ドラッグ）
- タッチ開始が紙の外周 **端ゾーン**（フラップ領域）なら折り開始。それ以外は移動タップ。
- ドラッグ距離 → フラップ角度（0°〜180°）。90° を越えて離すと確定、未満で離すとバネで戻る。
- 折られたフラップの端をつまんで逆方向にドラッグすれば折り戻し。
- 描画は Canvas 2D。フラップ表面・裏面をオフスクリーンキャンバスに描き、角度に応じて cos で横（縦）方向スケール＋落ち影を描く簡易 3D。

### 3.4 ヒント（無操作時）
- 8秒無操作で、正解の（道がつながる）フラップの端が風でふわっと2回めくれる。以後15秒ごと。
- 操作した時点でタイマーリセット。

### 3.5 ページめくり
- クリア後、紙全体が右下から左へめくれ、下から次の面の紙が現れる（本の見開きの因果）。
- 進捗表示は文字を使わず、机の左側に **めくり終えた紙の束** が積み上がることで示す。

## 4. ステージ構成（10面）

| 面 | 舞台 | 教える／試すこと |
|---|---|---|
| 1 | 家の前の庭 | 道が右で川に途切れる。右端を折ると橋がかかる。**最初の折り** |
| 2 | 森の入口 | 左端を折る（方向の一般化） |
| 3 | 小川 | 下端を折る（上下方向） |
| 4 | 花畑 | 上端を折る |
| 5 | 分かれ道 | 折れる端が2つ。片方は湖（通れない）、片方が道。**選択** |
| 6 | 山道 | 折った先で道が曲がる。折る前は行き先が見えない |
| 7 | 吊り橋 | 折る → 歩く → 折り戻す（ハナはフラップの外）→ 別の端を折る。**順序** |
| 8 | 洞窟 | ハナの上には折れない。先にハナを動かす必要がある |
| 9 | 雨の丘 | 7と8の複合 |
| 10 | おばあちゃんの村 | 総まとめ。到着で終幕 |

各面のデータは `levels.js` に JSON で定義（表・裏のタイル、開始位置、ゴール位置、正解フラップ）。実装後、4歳児プレイテストで並び替え・削減する前提。

## 5. アート方針

- **紙**: 生成りの紙色にノイズ（繊維）テクスチャ。裏面はやや暗い暖色で「裏」と分かる。折り目には影。
- **絵**: 版画風の太い輪郭 + 水彩風の塗り（輪郭と塗りをわざと少しずらす「版ずれ」）。すべて Canvas で手続き描画（画像アセットなし）。
- **主人公 ハナ**: 赤い帽子と黄色いかばん。歩き・止まる（向こうを見る）・しゃがむ・抱きつくの4状態。
- **ゴール**: おばあちゃんが家の前で手を振り続ける（常に動く＝目を引く）。
- **机**: 紙の外側は木目の机。縦横どちらの画面でも紙は中央に収まり、余白は机。

## 6. 技術構成

```
index.html          … 1ファイルで起動。viewport固定・ピンチ無効・safe-area対応
manifest.webmanifest… ホーム画面追加でフルスクリーン
src/main.js         … 起動・リサイズ・ループ
src/paper.js        … 紙モデル（表裏タイル・フラップ状態・合成グリッド）
src/fold.js         … ドラッグ入力→折り角度・確定/復帰・当たり判定
src/walker.js       … ハナの経路探索と歩行アニメ
src/render.js       … 紙・折り・キャラ・机の描画
src/art.js          … タイル絵とキャラの手続き描画
src/audio.js        … Web Audio 効果音（紙擦れ・パタン・足音・ボヨン・チャイム・ページめくり）
src/hint.js         … 無操作タイマーと風のめくれ
src/levels.js       … 10面のデータ
docs/               … 本プラン等
```

- 依存ライブラリなし。`index.html` をそのまま開けば動く。
- 入力は Pointer Events（タッチ・マウス両対応）。
- 画面回転・リサイズ時は紙のスケールを再計算するだけで状態は保持。
- 公開は GitHub Pages（`main` ブランチ直下）。
