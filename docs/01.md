## 1. コンセプト

緑の「もこもこ」(細胞の集まり)を、指でなでて削ると、削った反対側から細胞が生えて動く。
プレイヤーは「進め」と言われない。ゴールの光る花が画面の先で呼吸するように光っていて、
なでると動く感触が最初の 3 秒で分かる。それだけで進みたくなる、を目指す。

### Wordless interaction の守り方(設計原則)

| 原則 | 本作での具体化 |
|---|---|
| 知覚されたアフォーダンス | スライムは常に小さく脈動し「触っていいもの」に見せる。地面は苔の質感で「乗れる」、穴は暗く「落ちる」と分かる |
| 顕著なシグニファイア | ゴールの花は呼吸するように発光し、粒子が舞う。画面外なら画面端で光がにじむ |
| 物理的因果 | 指が触れた細胞がその場で「パッ」と散り、同時に反対側が「ぷくっ」と膨らむ。指=消しゴムの直感 |
| 自然な写像 | 右を削れば左に生える(=左へ寄る)。指の動きと結果の向きが常に対応 |
| 知覚的な不完全さ | 開始時、スライムが「乗り越えられそうで越えられない」段差の前にいる。狭い隙間は「細くすれば通れそう」に見える幅にする |
| 即時の視覚フィードバック | 触れた瞬間に粒子・波紋・音。遅延ゼロ。何もしなくてもスライムがゆっくり息をしている |
| 説明の代わりに世界 | 最初のステージは「右になだらかに下る坂」。何もしなくてもスライムが少し右へ垂れて、進行方向を世界が示す |

### 起動から最初の 10 秒
1. 起動直後にタイトル画面はない。いきなり森の中にスライムがいて、ゆっくり呼吸している。
2. スライムの周りに、指の形ではなく「なでる軌跡」のような光の筋が 1 度だけふわっと流れる(手本のデモ)。文字・矢印・手アイコンなし。
3. 画面のどこかを触ると音が有効化され、以後は何も案内しない。
4. 削ると散る/生える。地面が坂になっていて右へ自然に流れる。右端でゴールの花が光っている。

## 2. ゲームメカニクス

### 2.1 スライムの表現(簡易ソフトボディ)
- N 個(60〜120)の「細胞」粒子。各細胞は円。
- 細胞同士は近接するとバネ的に引き合い/反発(SPH 風の距離ベース力)。
- 重力・地面衝突・摩擦。細胞の集合体が「垂れて」「転がる」ように振る舞う。
- 描画は各細胞を大きめのソフト円で重ね書き→ しきい値でマスク(メタボール風)して 1 つの塊に見せる。目は 2 つ(黒丸+ハイライト)を重心付近に描き、生き物感を出す。
- 全細胞数は常に一定(削ると同数を再生)。

### 2.2 削る・生える
- タッチ/ドラッグの軌跡上の一定半径内にある細胞を消す(消す位置に散る粒子+音)。
- 消えた数と同じ数を、残った細胞群のうち **削った位置から最も遠い側** の表面付近に、少し外向きにずらして生成する(原作の「反対側から生える」)。
- 再生した細胞は初速 0。塊全体の重心が指と反対へ移り、重力・傾斜で移動が生じる。
- マルチタッチ対応(2 本指で両側を削って細くする、など)。

### 2.3 移動と地形
- 地形はステージごとに折れ線 + 塗りつぶし(苔・土)。当たり判定は線分との距離。
- 坂を転がる、段差は「上側を削って下を生やす」で登る、狭い隙間は細くして通る。
- 落下: 画面下に落ちたら、直前の安定位置(最後に地面接触していた重心)にふわっとフェードして再出現。音は「ぽよん」。ペナルティなし。

### 2.4 ゴール
- 光る花(または光るきのこ)。スライムの重心が花に触れると花が大きく開き、胞子(光の粒)が舞い、
  画面がゆっくり明るくなって次のステージにフェード。数秒後に自動で次へ。
- 最終ステージのクリア後は、集めた花が全部咲いた森が表示され、触るとまた 1 から遊べる。

### 2.5 カメラ
- スライム重心を追従(スムージング)。縦/横で表示領域が変わるため、ステージは「横長でも縦長でも進める」ようにデザイン:
  - 横画面: 横スクロール主体。
  - 縦画面: 画面幅が狭くなる分、カメラのズームを少し引く(スライムが同じ相対サイズに見える)。
- ゴールが画面外にあるときは、その方向の画面端が淡く光る(文字・矢印なし)。

## 3. ステージ構成(初期 3 つ・1 ステージ 1 概念)

| # | 学ぶこと | 地形 | 世界からの誘い |
|---|---|---|---|
| 1 | なでると削れて動く | 右へゆるく下る坂 → ゴール | 放置してもスライムがわずかに右へ垂れる。右端に花 |
| 2 | 削って登る | 途中に低い段差(スライムの半分の高さ) | 段差の上で花が光る。段差の角は丸く、乗れそうに見せる |
| 3 | 細くして通る | 低い天井のトンネル(スライム高さの 1/3) | トンネル向こうで花が光り、光がトンネルから漏れてくる |

以後のステージ候補(承認後・別プラン): 小さな穴(落下)、シーソー、風で舞う胞子、など。

## 4. 見た目・音

- 配色: 背景は深緑〜青緑のグラデーション、地面は苔の黄緑、スライムは明るい黄緑+内側にほのかな発光。ゴールは暖色(黄〜桃)の光で「ここだけ違う」と分かる。
- 背景に薄いきのこ・草のシルエットを多層パララックス(軽量に、数十個の図形のみ)。
- 全描画はコード(パス・グラデーション)で行い、画像ファイルなし。
- 効果音(Web Audio 合成):
  - 削る: 短い「ぷち」(ノイズ+ハイパスの短い減衰)
  - 生える: 「ぷくっ」(サイン波の短い上昇)
  - 着地: 低い「ぽよ」
  - ゴール: アルペジオ(3〜4 音)+きらきら
  - 落下復帰: 柔らかい下降音
- BGM はなし(静かな環境で子どもが操作音に集中できる)。

## 5. 技術・ファイル構成

```
index.html          ... 単一エントリ。meta viewport, apple-mobile-web-app 設定
src/main.js         ... 起動・ループ・リサイズ・向き対応
src/blob.js         ... 細胞粒子・力学・削り/再生
src/terrain.js      ... 地形定義・衝突
src/levels.js       ... ステージデータ(配列)
src/render.js       ... 描画(メタボール、背景、ゴール、演出)
src/input.js        ... タッチ/マウス(Pointer Events)、マルチタッチ
src/audio.js        ... Web Audio 合成効果音
src/save.js         ... localStorage
docs/01.md          ... 本プラン
```

- ES Modules を `<script type="module">` で読み込む。バンドラなし。
- iOS 対応:
  - `touch-action: none`、ダブルタップズーム・長押し選択・スクロールバウンスを CSS/JS で無効化。
  - `100dvh` と `visualViewport` でアドレスバー分を吸収。
  - 初回タッチで `AudioContext.resume()`。
  - `orientationchange`/`resize` でキャンバスを再構成、devicePixelRatio 対応。
  - ホーム画面追加時のフルスクリーン設定(`apple-mobile-web-app-capable`)。
- 物理はサブステップ固定 dt(例 1/120s ×2)で安定化。細胞数は端末性能に応じて 60〜120 の範囲で調整可能な定数。
